# 神經網路權重隨機初始化與對稱性破除（Symmetry Breaking）學習筆記

本筆記整理自神經網路基礎課程，探討權重初始化的重要性、對稱性破除（Symmetry Breaking）機制，以及實務上的初始化技巧。

---

## 1. 為什麼不能將權重（W）初始化為零？

在訓練神經網路時，將權重 $W$ 全部初始化為 0 會導致嚴重的問題。這與邏輯回歸（Logistic Regression）不同（邏輯回歸將權重設為零是可行的）。

* **完全對稱問題**：若將所有權重 $W$ 初始化為零，同一層隱藏層中的所有單元（hidden units）將會計算出完全相同的激活值（Activation）。
* **梯度完全相同**：在反向傳播（Backpropagation）過程中，由於對稱性，這些隱藏單元的梯度 $\text{d}W$ 也會完全相同。
* **無法學習不同特徵**：經過梯度下降（Gradient Descent）更新後，這些單元依然會保持對稱。無論訓練多久，多個隱藏單元實際上只相當於**一個單元**在運作，使得增加網路的寬度與深度失去意義。

---

## 2. 對稱性破除（Symmetry Breaking）

為了解決上述對稱性問題，必須對權重進行隨機初始化，這一過程稱為**對稱性破除**。

* **解決方案**：使用隨機數（例如高斯分佈/標準常態分佈）來設定初始權重，使每個隱藏單元從計算不同的函數開始。
* **偏置項（$b$）的例外**：偏置項 $b$ 可以安全地初始化為零。只要權重 $W$ 是隨機初始化的，就能達成對稱性破除的效果。

---

## 3. 如何正確初始化權重？

通常建議使用微小的隨機值來初始化權重矩陣：

### 程式碼範例 (Python / NumPy)

```python
import numpy as np

# 假設 shape 為 (current_layer_size, previous_layer_size)
W = np.random.randn(*shape) * 0.01
b = np.zeros((current_layer_size, 1))
```

### 為什麼乘以 $0.01$（微小的隨機值）？

1. **避免激活函數飽和**：
   若權重太過龐大，計算出的 $Z = W \cdot X + b$ 值會過大或過小。在 `tanh` 或 `sigmoid` 等激發函數中，這會使輸出落入兩端的「平坦區域」（Saturated Region）。
2. **加速學習過程**：
   在平坦區域中，激發函數的導數（斜率/梯度）非常趨近於 0，會導致梯度下降更新的速度變得極度緩慢。
3. **輸出層的影響**：
   即使中間隱藏層未使用 `sigmoid`，若輸出層用於二元分類（Binary Classification）並使用了 `sigmoid`，過大的隱藏層權重仍可能傳遞出過大的 $Z$ 值，進而降低整體學習效率。

---

## 4. 深層網路的特殊考量

* **淺層網路**：對於只有 1~2 層隱藏層的淺層網路，乘以 `0.01` 通常運作得很好。
* **深層網路（Deep Neural Networks）**：在訓練極深的神經網路時，單純乘以 `0.01` 可能不是最佳選擇，容易導致**梯度消失（Exploding/Vanishing Gradients）**問題。
* **進階初始化方法**：
  * **He Initialization**（適用於 ReLU）：$\text{std} = \sqrt{\frac{2}{n^{[l-1]}}}$
  * **Xavier / Glorot Initialization**（適用於 tanh）：$\text{std} = \sqrt{\frac{1}{n^{[l-1]}}}$

---

## 5. 總結對照表

| 參數 | 初始化方法 | 理由 |
| :--- | :--- | :--- |
| **權重 $W$** | 必須隨機初始化（如乘以 $0.01$） | 破除對稱性，讓不同神經元學習不同的特徵與模式 |
| **偏置項 $b$** | 可以初始化為零 ($0$) | 不影響對稱性破除，計算簡便 |
| **初始值大小** | 傾向選擇微小隨機值 | 防止激發函數飽和，維持合理的梯度下降速度 |
