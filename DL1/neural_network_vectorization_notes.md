# 深度學習筆記：神經網路向量化（Vectorization）計算

本筆記整合神經網路前向傳播（Forward Propagation）的向量化實作核心概念、符號規範與數學原理。其核心目的在於說明如何透過**矩陣運算（Matrix Operations）**取代傳統低效的 `for` 迴圈，達成多樣本平行計算的高效輸出。

---

## 1. 核心概念：神經網路與邏輯迴歸的關係

神經網路的計算可以看作是**多次重複的邏輯迴歸（Logistic Regression）**。在神經網路的每個節點中，都包含兩個核心步驟：

1. **計算線性組合 (Linear Combination)：**
   $$z = w^T x + b$$
2. **套用激活函數 (Activation Function)：**
   $$a = \sigma(z)$$
   *通常使用 Sigmoid 函數，藉此引入非線性特徵。*

當網路節點與層數增加時，逐一透過 `for` 迴圈計算會造成極大的效能瓶頸。因此，實務上會將參數堆疊成矩陣，利用向量化進行平行運算。

---

## 2. 標記符號指南 (Notation)

為了精準區分不同層數、不同節點以及不同訓練樣本，定義以下標記規範：

| 符號種類 | 代表意義 | 範例與解讀 |
| :--- | :--- | :--- |
| **上標方括號** $[l]$ | **層數 (Layer number)** | $a^{[1]}$ 代表第一層（隱藏層）的激活值 |
| **上標圓括號** $(i)$ | **第 $i$ 個訓練樣本** | $x^{(1)}$ 代表第一筆訓練資料 |
| **下標** $i$ | **該層的第 $i$ 個節點** | $a^{[1]}_1$ 代表第一層中第一個節點的輸出值 |
| **大小寫區分** | **單一樣本 vs. 批量矩陣** | 小寫 $x$ 代表單一樣本；大寫 $X$ 代表多樣本堆疊的矩陣 |

> **註記：** 輸入特徵向量/矩陣可視為第 0 層的輸出，即 $x = a^{[0]}$ 或 $X = A^{[0]}$；而最終層的預測輸出則為 $\hat{y} = a^{[L]}$ 或 $\hat{Y} = A^{[L]}$。

---

## 3. 矩陣的空間結構與維度想像

將單一樣本推廣至 $m$ 個訓練樣本時，向量化的關鍵在於將資料與中間運算結果水平堆疊：

* **水平方向（由左至右）：** 代表**不同的訓練樣本**（從 $1$ 到 $m$）。當你從左向右掃描矩陣時，是在遍歷整個訓練集。
* **垂直方向（由上至下）：** 代表**神經節點或輸入特徵**。每一列（Row）對應到該層中的不同神經元。

### 矩陣元素位置意義範例：
矩陣 $A^{[1]}$ 中第 1 列第 1 行的數值，代表：
$$
\text{「第一個訓練樣本」在「第一層第一個隱藏單元」的激活值 }
a_{1}^{[1](1)}
$$

---

## 4. 向量化正向傳播（Forward Propagation）公式

對於一個兩層（Single Hidden Layer）的神經網路，將 $m$ 個樣本堆疊為大寫矩陣 $X$（即 $A^{[0]}$）後，正向傳播只需以下**四行關鍵公式**即可達成平行計算：

$$Z^{[1]} = W^{[1]}A^{[0]} + b^{[1]}$$
$$A^{[1]} = \sigma(Z^{[1]})$$
$$Z^{[2]} = W^{[2]}A^{[1]} + b^{[2]}$$
$$A^{[2]} = \sigma(Z^{[2]})$$

### 運算背後的兩個數學關鍵：
1. **矩陣乘法性質：** 計算 $W^{[1]}X$ 時，根據矩陣乘法定義，結果矩陣的第一行自動對應 $W^{[1]}x^{(1)}$，第二行自動對應 $W^{[1]}x^{(2)}$，天生具備平行計算能力。
2. **Python 廣播機制（Broadcasting）：** 偏置項 $b^{[1]}$ 為一個列向量（Column Vector）。在計算 $W^{[1]}X + b^{[1]}$ 時，Python 會自動將 $b^{[1]}$ 複製擴展至矩陣的每一行，確保每個樣本皆正確加上對應的偏置。

---

## 5. 總結與啟示

1. **計算對稱性：** 各層之間的算式結構高度一致（例如 $Z^{[1]}$ 與 $Z^{[2]}$ 的公式形態相同），差別僅在於層數索引 $[l]$ 的遞增。
2. **深層網路擴充：** 無論神經網路層數多深，均是將計算線性組合 $Z$ 與計算激活值 $A$ 這兩個核心步驟重複執行。
3. **激活函數靈活性：** 雖然範例以 Sigmoid 函數 $\sigma(z)$ 為主，實務中可依需求替換為 ReLU、Tanh 或其他激活函數。
