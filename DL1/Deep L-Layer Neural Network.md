# 深度學習筆記：深層 L 層神經網路 (Deep L-Layer Neural Network)

---

## 1. 深層神經網路的基本概念

* **深度的定義**：深度是一個程度問題。
  * **邏輯回歸 (Logistic Regression)**：被視為非常淺的模型。
  * **深層模型**：擁有更多隱藏層的神經網路。
* **演進歷程**：深層神經網路是結合了邏輯回歸、單隱藏層神經網路、向量化 (Vectorization) 以及權重隨機初始化 (Random Initialization) 等概念的產物。
* **模型效能**：機器學習社群近年發現，深層神經網路能學習到許多傳統淺層模型無法有效處理的複雜函數。

---

## 2. 層數的計算規則

* **不計入輸入層**：在計算神經網路的層數時，**輸入層 (Input Layer) 不算入**，僅計算隱藏層與輸出層。
* **範例說明**：
  * **邏輯回歸**：技術上可被視為「1 層」的神經網路。
  * **2 層神經網路**：包含 1 個隱藏層 + 1 個輸出層。
  * **4 層神經網路**：包含 3 個隱藏層 + 1 個輸出層。

---

## 3. 關鍵符號與表示法 (Notation)

為了精確描述深層網路，使用以下標準數學符號：

| 符號 | 意義說明 |
| :--- | :--- |
| $L$ | 代表網路中的總層數（例如：$L = 4$） |
| $l$ | 代表目前的層級索引（$l = 1, 2, \dots, L$） |
| $n^{[l]}$ | 代表第 $l$ 層的節點（單元）數量 |
| $n^{[0]} = n_x$ | 輸入層的特徵數量 |
| $n^{[L]}$ | 最後輸出層的單元數量 |

---

## 4. 變數與激活過程

### 激活值 (Activations)
* $a^{[l]}$：第 $l$ 層的激活值，計算方式為 $a^{[l]} = g^{[l]}(z^{[l]})$。
* $a^{[0]} = X$：輸入特徵向量，即為第 0 層的激活值。
* $a^{[L]} = \hat{y}$：最後一層的激活值，即為網路的最終預測輸出值。

### 權重與偏差 (Weights & Biases)
* $W^{[l]}$：用於計算第 $l$ 層線性輸出 $z^{[l]}$ 的權重矩陣。
* $b^{[l]}$：用於計算第 $l$ 層線性輸出 $z^{[l]}$ 的偏差向量。

  # 神經網路前向傳播公式 (Forward Propagation Equations)

在深層神經網路中，第 $l$ 層的線性計算與激活過程公式如下：

$$z^{[l]} = W^{[l]}a^{[l-1]} + b^{[l]}$$

$$a^{[l]} = g^{[l]}(z^{[l]})$$


### 符號說明：
* $l$：目前的層級索引 ($l = 1, 2, \dots, L$)
* $W^{[l]}$：第 $l$ 層的權重矩陣 (Weight matrix)
* $b^{[l]}$：第 $l$ 層的偏差向量 (Bias vector)
* $a^{[l-1]}$：上一層 (第 $l-1$ 層) 的激活輸出向量 (當 $l=1$ 時，$a^{[0]} = X$)
* $z^{[l]}$：第 $l$ 層的線性組合輸出 (Linear output)
* $g^{[l]}(\cdot)$：第 $l$ 層使用的激活函數 (Activation function，如 ReLU, Sigmoid 等)
* $a^{[l]}$：第 $l$ 層最終輸出的激活值 (Activation output)

---

## 5. 開發建議與實務心法

* **隱藏層數量作為超參數 (Hyperparameter)**：在解決特定的機器學習問題時，很難預先確定需要多深的網路。
* **調參策略**：建議將隱藏層數量視為超參數，嘗試不同的數值組合，並透過**保留交叉驗證數據 (Holdout Cross-Validation Data)** 或 **開發集 (Development Set / Dev Set)** 來評估與優化模型效果。
