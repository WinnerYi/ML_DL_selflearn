# 神經網絡激活函數（Activation Functions）學習筆記與觀念總整理

## 1. 激活函數的核心作用與「非線性」的必要性

在神經網絡的每一層中，我們會在線性計算 $z = Wx + b$ 之後套用一個激活函數 $g(z)$，得到輸出 $a = g(z)$。

### 為什麼神經網絡必須使用「非線性」激活函數？
* **計算複雜函數：** 非線性轉換才能賦予神經網絡擬合複雜、非線性邊界的能力。
* **防止「層數塌陷」（Layer Collapse）：** 若所有隱藏層都使用線性激活函數 $g(z) = z$（又稱**恆等激活函數 Identity Activation Function**），無論網絡疊加多少層，整體計算依舊只是一個單層的線性模型。

> **數學證明（層數塌陷）：**
> * 第一層輸出：
$$a^{[1]} = W_1 x + b_1$$
> * 第二層輸出：
$$a^{[2]} = W_2 a^{[1]} + b_2$$
> * 代入後展開：
$$a^{[2]} = W_2 (W_1 x + b_1) + b_2 = (W_2 W_1) x + (W_2 b_1 + b_2)$$
> * 設 $W' = W_2 W_1$ 且 $b' = W_2 b_1 + b_2$，則 $a^{[2]} = W'x + b'$。這證明多層線性網絡的表達能力**並不比無隱藏層的標準邏輯迴歸（Logistic Regression）更強**。

## 2. 四大常見激活函數深度對比

下表整合了各函數的特性、優缺點及**反向傳播（Back-propagation）時的導數（$\frac{d}{dz}g(z)$）計算**。利用已算出之激活值 $a = g(z)$ 來計算導數，能大幅提升運算效率：

| 激活函數 | 公式 $g(z)$ | 輸出範圍 | 導數公式 $\frac{d}{dz}g(z)$ | 優點 / 適用場景 | 缺點 / 潛在風險 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Sigmoid** | $\frac{1}{1 + e^{-z}}$ | $(0, 1)$ | $a(1 - a)$ | 輸出可視為機率，**僅建議用於二元分類的輸出層**。 | 當 $\|z\|$ 極大或極小時，斜率趨近於 $0$，會引發**梯度消失（Vanishing Gradient）**，嚴重減慢學習速度。 |
| **tanh**<br>*(雙曲正切)* | $\frac{e^z - e^{-z}}{e^z + e^{-z}}$ | $(-1, 1)$ | $1 - a^2$ | 為 Sigmoid 的縮放與平移版本，具**零中心化（Zero Mean）**特性，能讓下一層學習更容易。隱藏層效果**幾乎總是優於 Sigmoid**。 | 同樣存在 $\|z\|$ 極大或極小時**梯度消失**的問題。 |
| **ReLU**<br>*(線性整流)* | $\max(0, z)$ | $[0, \infty)$ | $g'(z)=0\ (z<0),\ 1\ (z>0),\ 0\text{ 或 }1\ (z=0)$ | **目前最受歡迎的預設首選**。當 $z > 0$ 時斜率恆為 $1$，無梯度消失問題，訓練速度遠快於 tanh 與 Sigmoid。 | 當 $z < 0$ 時，梯度恆為 $0$（神經元可能停止更新，即 Dying ReLU）。 |
| **Leaky ReLU** | $\max(0.01z, z)$ | $(-\infty, \infty)$ | $0.01\ (z<0),\ 1\ (z>0),\ 0.01\text{ 或 }1\ (z=0)$ | 解決了 ReLU 在負值區域梯度為 $0$ 的問題，給予 $0.01$ 的微小斜率。 | 實務效果通常不錯，但整體普及度仍略遜於標準 ReLU。 |

> **關於 $z = 0$ 時的導數說明：**
> 在數學上，ReLU 與 Leaky ReLU 在 $z = 0$ 處不可微（導數未定義）。但在軟體實作中，實際採樣到 $z$ 恰好等於 $0$ 的機率極低，實務上將其導數隨機指定為 $0$、$0.01$ 或 $1$ 均不影響結果（這在優化理論中稱為**次梯度 Subgradient**），梯度下降法依然能正常運作。

## 3. 激活函數選擇指南與實務建議

在搭建神經網絡架構時，可遵循以下經驗法則（Rule of Thumb）：

### 按網絡架構選擇
* **隱藏層（Hidden Layers）：**
  * **首選預設：** **ReLU**。如果不確定用什麼，直接使用 ReLU 是最安全的選擇。
  * **次要嘗試：** 亦可嘗試 **tanh**（需留意梯度消失）或 **Leaky ReLU**。
  * **規則：** 隱藏層**必須**使用非線性激活函數，否則深層結構將失去意義。
* **輸出層（Output Layer）：**
  * **二元分類（Binary Classification）：** 使用 **Sigmoid**（輸出 $0 \sim 1$ 的機率值）。
  * **連續值迴歸問題（Regression Problems）：** 可使用**線性激活函數** $g(z) = z$（例如預測房價）。若預測目標恆大於等於 $0$，有時亦會在輸出層改用 **ReLU**。

### 實務疊代原則
在深度學習中，很難單憑理論預知哪種函數最適合特定問題。最佳的開發流程為：
1. **多方嘗試：** 在模型中交叉測試不同的激活函數組合。
2. **驗證集評估：** 務必透過**驗證集/開發集（Validation Set / Dev Set）**的表現來客觀評估，最終保留效果最佳的函數。
