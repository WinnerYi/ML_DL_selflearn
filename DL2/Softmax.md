# Softmax 迴歸與多分類神經網路訓練：核心原理與實務全解

在機器學習的建模路徑中，從二元分類（Binary Classification）跨越到多分類（Multiclass Classification）代表了從處理「是非題」到處理「選擇題」的戰略轉型。在現實世界的視覺辨識任務中，我們不僅要辨識一張圖是否為貓，更需要從多個潛在類別（如貓、狗、小雞）中識別出目標，或判斷其不屬於任何已知類別。這種需求驅使我們將神經網路的輸出結構從單一單元擴展為機率向量。

---

## 1. 多分類問題的建構與背景分析

在多分類框架下，我們定義類別總數為參數 $C$。與二元分類僅輸出一個值（代表 $P(y=1 \mid x)$）不同，多分類模型必須針對每個類別產生一個預測機率。

### 類別索引系統
為了精確定義輸出，我們採用從 $0$ 到 $C-1$ 的索引系統。以常見的視覺辨識任務為例：
* **0**：其他 (Other / None of the above)
* **1**：貓 (Cat)
* **2**：狗 (Dog)
* **3**：小雞 (Baby Chick)

在此案例中，$C = 4$。為了映射這四個類別，神經網路的輸出層（第 $L$ 層）必須具備與類別數相等的單元數，即 $n^{[L]} = C$。

### 輸出向量的機率特質
模型最終產生的預測向量 $\hat{y}$（即 $a^{[L]}$）是一個 $C 	imes 1$ 的向量，其中每一個元素 $\hat{y}_i$ 代表 $P(y=i \mid x)$。為了讓輸出具備有效的機率統計意義，模型必須滿足兩個核心前提：
1. **非負性**：每一類別的預測值必須 $\ge 0$。
2. **單位和約束**：所有類別的元素總和必須精確等於 1 ($\sum \hat{y}_i = 1$)。

為了實現這種將線性輸出轉譯為機率分佈的機制，我們必須引入 Softmax 激活函數。

---

## 2. Softmax 激活函數：數學機制與數值模擬

Softmax 激活函數在神經網路的最後一層擔任「轉換器」的角色，它接收線性計算產生的原始分數（Logits），並將其映射至區間 $[0,1]$ 且總和為 1 的空間中。

### 計算三階段
1. **線性輸出**：計算輸出層的線性加權和：
   $$Z^{[L]} = W^{[L]} A^{[L-1]} + b^{[L]}$$
2. **指數化 (Exponentiation)**：計算臨時變數 $t = e^{Z^{[L]}}$。透過指數函數，我們確保了所有數值皆為正數，並放大了原始數值間的差異。
3. **歸一化 (Normalization)**：將各個指數結果除以總能量，確保向量總合為 1：
   $$a_i^{[L]} = \frac{t_i}{\sum_{j=1}^{C} t_j}$$

### 數值範例拆解
若模型對某樣本的線性輸出為 $Z^{[L]} = [5, 2, -1, 3]^T$，計算過程如下：

| 類別索引 ($i$) | $Z_i^{[L]}$ | 指數化 $t_i = e^{Z_i^{[L]}}$ | 最終機率 $a_i^{[L]}$ ($t_i / 176.3$) | 預測意義 |
| :--- | :--- | :--- | :--- | :--- |
| **0 (其他)** | 5 | $\approx 148.4$ | **0.842** | 84.2% 為其他類別 |
| **1 (貓)** | 2 | $\approx 7.4$ | **0.042** | 4.2% 為貓 |
| **2 (狗)** | -1 | $\approx 0.4$ | **0.002** | 0.2% 為狗 |
| **3 (小雞)** | 3 | $\approx 20.1$ | **0.114** | 11.4% 為小雞 |
| **總和** | - | **176.3** | **1.000** | - |

### 非獨立性分析
與 ReLU 或 Sigmoid 等激活函數不同，Softmax 具有顯著的**「非獨立性」**。單一輸出單元 $a_i^{[L]}$ 的數值不僅取決於自己的 $Z_i^{[L]}$，還取決於整個向量中所有元素的總能量（分母）。這種機制迫使類別之間產生競爭關係：若某一類別的機率上升，其餘類別的機率勢必下降。

## 3. 決策邊界（Decision Boundary）與模型複雜度分析

理解了 Softmax 如何產生機率後，我們需探討它如何在特徵空間中劃分邊界。

* **無隱藏層的 Softmax 迴歸**：若輸入直接連接至 Softmax 層，模型本質上是在各類別間建立線性決策邊界。在空間視覺化中，模型會將空間劃分為多個線性區域，每個區域對應於該處機率值最高的類別。雖然它可以處理多個類別，但各類別間的邊界（如黃色區域與紫色區域之間）仍是線性的。
* **深度神經網路（DNN）的賦能**：當我們在 Softmax 之前加入多個隱藏層時，模型便擁有了學習非線性表示的能力。這使得 Softmax 能夠基於高層次的抽象特徵，劃分出極其複雜且扭曲的非線性決策邊界。

## 4. 深度對比：Softmax、Hard Max 與邏輯迴歸之關聯

「Softmax」之名源於它相對於「Hard Max」的平滑特質，這在優化過程中至關重要。

| 特性 | Softmax (平滑最大值) | Hard Max (硬最大值) |
| :--- | :--- | :--- |
| **輸出形式** | 連續的機率分佈 (如 $[0.84, 0.11, \dots]$) | 離散的獨熱輸出 (如 $[1, 0, 0, 0]$) |
| **可微性** | 全域可微，提供豐富的梯度資訊 | 不連續，梯度幾乎處處為零 |
| **訓練價值** | 允許誤差微量傳遞，支撐梯度下降 | 無法透過反向傳播更新參數 |

### 「Soft」的重要性
Hard Max 僅關心「誰是贏家」，這會導致梯度在訓練過程中消失。Softmax 則保留了預測與真實標籤之間的細微差距，確保每個參數都能獲得導航訊號。

### 泛化邏輯：當 $C=2$ 時
Softmax 是邏輯迴歸（Logistic Regression）的數學泛化。在 $C=2$ 的情況下，Softmax 會輸出兩個機率值且總和為 1。由於 $P(y=1) = 1 - P(y=0)$，其中一個輸出在數學上是冗餘的。邏輯迴歸正是利用了這一點，僅計算一個機率，而 Softmax 則透過兩個輸出單元維持了結構的對稱性。

## 5. 損失函數與成本函數：優化目標的確立

一旦我們將輸出定義為機率分佈，就需要一種量化「預測分佈」與「真實分佈」之間差異的方法。

### 交叉熵損失（Cross-entropy Loss）
$$\mathcal{L}(\hat{y}, y) = -\sum_{j=1}^{C} y_j \log \hat{y}_j$$

以一張「貓」的影像為例（真實標籤為 index 1，即 $y = [0, 1, 0, 0]^T$）。在此情況下，所有 $y_j = 0$ 的項都會消失，損失函數簡化為：
$$\mathcal{L}(\hat{y}, y) = -\log \hat{y}_1$$

### 統計學意義與 MLE
從**最大似然估計（Maximum Likelihood Estimation, MLE）**的角度來看，最小化交叉熵損失等同於最大化正確類別的觀測機率。當預測值 $\hat{y}_1$ 越接近 1（即模型認為這是一張貓的可能性越高 $,\log \hat{y}_1$ 就越接近 0，損失隨之降至最低。

全體 $m$ 個訓練樣本的總成本函數 $J$ 則是所有樣本損失的平均：
$$J(W, b) = \frac{1}{m} \sum_{i=1}^{m} \mathcal{L}(\hat{y}^{(i)}, y^{(i)})$$

## 6. 高效實作：向量化與反向傳播梯度公式

在大規模數據運算的實作中，為了提升硬體效率，我們必須使用向量化表示法。

### 矩陣維度定義
* **標籤矩陣 $Y$**：維度為 $C \times m$，由 $m$ 個樣本的獨熱編碼列向量組合而成。
* **預測矩陣 $\hat{Y}$**：維度同樣為 $C \times m$，儲存了所有樣本的 Softmax 輸出。

### 核心梯度與架構思維
在反向傳播的起點，輸出層的誤差梯度公式表現出驚人的簡潔性：
$$dZ^{[L]} = \hat{Y} - Y$$

此公式直觀地描述了「預測與現實的誤差」，並作為連鎖律（Chain Rule）的源頭，將修正訊號傳回網路的前幾層。

> **技術文件架構師的實務建議**：在現代深度學習框架（如 TensorFlow 或 PyTorch）中，自動求導機制（Autodiff）已經接管了複雜的反向路徑計算。對於開發者而言，最核心的任務在於確保前向傳播（Forward Pass）的精確性。只要前向傳播的數學結構與機率約束（如 Softmax 的歸一化）正確無誤，框架便能高效且準確地推導出所有更新參數所需的梯度。掌握這些底層原理，是進行高級模型診斷與參數調優不可或缺的基石。
