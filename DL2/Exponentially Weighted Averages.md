# 指數加權平均（Exponentially Weighted Averages, EWA）完整學習筆記

指數加權平均（在統計學中也稱為指數加權移動平均，Exponentially Weighted Moving Average, EWMA）是一種常用的數據平滑技術。它同時也是後續理解多種比傳統梯度下降法（Gradient Descent）更快速、更先進的深度學習優化算法（如 Momentum, RMSprop, Adam 等）的核心理論基礎與關鍵機制。

---

## 一、 引入背景與觀念直覺

### 1. 倫敦氣溫範例
以倫敦一整年的每日氣溫數據為例：
* **原始數據的波動**：1 月 1 日的溫度約為 $40^\circ\text{F}$（約 $4^\circ \text{C}$）；5 月下旬（約第 118 天）的溫度約為 $60^\circ \text{F}$（約 $15^\circ	\text{C}$）。
* **趨勢特徵**：整體趨勢為年初較冷、夏季較熱、年底再次變冷。然而，直接畫出每日氣溫時，數據點會夾帶大量噪音（noisy）。
* **核心目的**：為了從帶有雜訊的每日觀測值中，計算出當地的局部平均值或平滑趨勢線，我們需要引入移動平均的計算方法。

## 二、 數學公式與遞迴推導

### 1. 核心計算公式
指數加權平均的疊代更新公式如下：

$$v_t = \beta v_{t-1} + (1 - \beta) \theta_t$$

* $v_t$：第 $t$ 天（或當前步驟）計算出的指數加權平均估計值。
* $v_{t-1}$：前一天的加權平均估計值。
* $	heta_t$：第 $t$ 天的實際觀測值。
* $ eta$：超參數（介於 $0$ 到 $1$ 之間），決定對過去數據的衰減權重與平滑程度。
* **初始化**：在第 1 天開始前，通常設定 $v_0 = 0$。

### 2. 疊代計算步驟（以 $\beta = 0.9$ 為例）
* 第 1 天 $v_1$：
$$v_1 = 0.9 v_0 + 0.1 \theta_1 = 0.1 \theta_1$$
* 第 2 天 $v_2$：
$$v_2 = 0.9 v_1 + 0.1 \theta_2$$
* 第 3 天 $v_3$：
$$v_3 = 0.9 v_2 + 0.1 \theta_3$$

### 3. 遞迴展開與權重指數衰減
將 $v_{100}$ 向後遞迴展開：

$$v_{100} = 0.1 \theta_{100} + 0.9 v_{99}$$

將 $v_{99} = 0.1 \theta_{99} + 0.9 v_{98}$ 代入：

$$v_{100} = 0.1 \theta_{100} + 0.9 (0.1 \theta_{99} + 0.9 v_{98}) = 0.1 \theta_{100} + 0.1(0.9) \theta_{99} + 0.9^2 v_{98}$$

持續展開後可得：

$$v_{100} = 0.1 \theta_{100} + 0.1(0.9)\theta_{99} + 0.1(0.9)^2	heta_{98} + 0.1(0.9)^3\theta_{97} + 0.1(0.9)^4\theta_{96} + \dots$$

**結論**：$v_t$ 本質上是當前與過去所有觀測值 $\theta_i$ 的加權總和（加權平均）。歷史觀測值的權重隨著時間推移呈**指數級衰減**（Exponential Decaying Function）。

## 三、 超參數 $\beta$ 的物理意義與天數估算

### 1. 平均天數估算法則（Rule of Thumb）
在實際計算中，將 $v_t$ 視為對過去約 $\frac{1}{1 - \beta}$ 天數據進行的平均。

* **當 $\beta = 0.9$ 時**：
  $$\frac{1}{1 - 0.9} = 10 \text{ 天}$$
  代表 $v_t$ 大致是過去 10 天氣溫的平均值。
* **當 $\beta = 0.98$ 時**：
  $$\frac{1}{1 - 0.98} = 50 \text{ 天}$$
  代表 $v_t$ 大致是過去 50 天氣溫的平均值。
* **當 $\beta = 0.5$ 時**：
  $$\frac{1}{1 - 0.5} = 2 \text{ 天}$$
  代表 $v_t$ 大致僅是過去 2 天氣溫的平均值。

### 2. 微積分原理與 $1/e$ 衰減
根據微積分中的極限公式，當 $\epsilon$ 很小時：

$$(1 - \epsilon)^{\frac{1}{\epsilon}}  pprox \frac{1}{e}  pprox 0.34 \sim 0.35$$

令 $\epsilon = 1 - \beta$：
* 當 $\beta = 0.9$（即 $\epsilon = 0.1$）時：
  $$0.9^{10} = (1 - 0.1)^{\frac{1}{0.1}}  pprox \frac{1}{e}  pprox 0.35$$
  經過 10 天後，歷史數據的權重已衰減到當天權重的約三分之一（$\frac{1}{e}$）。因此直覺上可視為平均過去 10 天的數據。
* 當 $ eta = 0.98$（即 $\epsilon = 0.02$）時：
  $$0.98^{50} = (1 - 0.02)^{\frac{1}{0.02}}  pprox \frac{1}{e}$$
  數據權重需要經過 50 天才會衰減至峰值的 $\frac{1}{e}$，故相當於平均過去 50 天的數據。

## 四、 不同的 $\beta$ 值對曲線的影響與折衷（Trade-off）

| 參數設定 | 估計平均天數 | 曲線平滑度 | 延遲（適應速度） | 雜訊與極端值抵抗力 |
| :--- | :--- | :--- | :--- | :--- |
| **$\beta = 0.98$<br>(高 $\beta$ 值)** | 約 50 天 | **非常平滑**<br>波形起伏極小。 | **高延遲（適應慢）**<br>當數據劇烈變化時，曲線適應緩慢，整體趨勢向右平移。 | **極佳**<br>幾乎不受單日異常波動或極端離群值影響。 |
| **$\beta = 0.5$<br>(低 $\beta$ 值)** | 約 2 天 | **不平滑**<br>曲線波動劇烈。 | **極低延遲（適應快）**<br>機能迅速跟上最新觀測值的變化。 | **極差**<br>極易受到單日噪音與離群值干擾。 |
| **$\beta = 0.9$<br>(中間折衷值)** | 約 10 天 | **適度平滑**<br>能清晰展現整體趨勢。 | **適度延遲**<br>維持合理的適應速度。 | **良好**<br>在濾除雜訊與保留趨勢之間取得平衡。 |

### 💡 為什麼高 $\beta$（如 0.98）會帶來明顯延遲？
當 $ eta = 0.98$ 時，更新公式給予過去累積的平均值高達 $0.98$ 的權重，而當前新觀測值僅獲得 $0.02$ 的權重。當實際數據發生劇烈轉折時，算法需要花費更多天數累積新數據的影響力，才能逐漸反映最新趨勢，因而產生物理上的「延遲」現象。

## 五、 記憶體與計算效率優勢

在深度學習中，當需要同時對神經網路中數百萬至數十億個參數計算移動平均時，EWA 展現出決定性的時空效率優勢：

| 比較維度 | 傳統移動窗口平均法（Moving Window） | 指數加權平均數（EWA） |
| :--- | :--- | :--- |
| **記憶體需求** | **高**：必須在記憶體中維護大小為 $N$ 的窗口，顯式儲存過去 $N$ 天的所有數據點。 | **極低**：只需在記憶體中維護單個實數變數 $v$，並隨新數據傳入進行覆寫更新。 |
| **計算複雜度** | **高**：每次更新需對窗口內所有 $N$ 個數據進行累加並除以 $N$。 | **極低**：每次更新僅需進行一次簡單的乘加運算（單行程式碼即可完成）。 |
| **適用場景** | 適合小數據量、需要精確固定窗口平均的場景。 | **最適合深度學習**：參數規模極大時的唯一可行方案。 |

## 六、 偏差修正（Bias Correction）

### 1. 為何需要偏差修正？
在實作中，通常初始化 $v_0 = 0$。這會導致在算法剛開始運行的「預熱階段（Warm-up phase）」，估計值會顯著偏低。

以 $ eta = 0.98$ 為例：
* **第 1 天 ($t=1$)**：
  $$v_1 = 0.98 v_0 + 0.02 	heta_1 = 0.98(0) + 0.02 \theta_1 = 0.02 \theta_1$$
  若第一天實際溫度 $	heta_1 = 40^\circ	\text{F}$，則估計值 $v_1 = 0.02 \times 40 = 0.8$，遠低於實際數值。
* **第 2 天 ($t=2$)**：
$$
v_2 = 0.98 v_1 + 0.02 \theta_2 = 0.98(0.02 	heta_1) + 0.02 	heta_2 = 0.0196 \theta_1 + 0.02 theta_2 
$$
  計算出的 $v_2$ 依然嚴重低於真實數值。

### 2. 偏差修正公式與數學原理
為了消除初始階段的偏差，我們不直接使用 $v_t$，而是計算修正後的估計值 $\hat{v}_t$：

$$\hat{v}_t = \frac{v_t}{1 - \beta^t}$$

其中 $t$ 為當前運行的步數/天數。

**以第 2 天 $t=2$ 為例驗證**：
* 修正分母為：$1 - \beta^2 = 1 - 0.98^2 = 0.0396$。
* 修正後數值：
  $$\hat{v}_2 = \frac{v_2}{1 - \beta^2} = \frac{0.0196 \theta_1 + 0.02 \theta_2}{0.0396}$$
* **數學解析**：分子權重之和（$0.0196 + 0.02 = 0.0396$）恰好等於分母 $0.0396$。經除法校正後，權重總和恢復為 $1$，使 $\hat{v}_2$ 成為 $	heta_1$ 與 $\theta_2$ 的正確加權平均數，成功消除初始偏差。

### 3. 長期行為與實際應用
* **長期趨勢**：當步數 $t$ 逐漸增大時，$\beta^t 	o 0$，分母 $1 - \beta^t 	o 1$。因此修正項影響力迅速消失，使得 $\hat{v}_t  pprox v_t$。未修正與已修正曲線會在後期完全重合。
* **機器學習實際應用**：
  * 在大多數深度學習優化器實作中，如果不極度關心初期預熱階段的精準度，常會選擇省略偏差修正，直接使用未修正的 $v_t$。
  * 若需要在訓練剛開始（初期步數）就獲得極其精確的參數或梯度估計，則必須實作偏差修正（例如 Adam 優化器中便完整內建了偏差修正機制）
