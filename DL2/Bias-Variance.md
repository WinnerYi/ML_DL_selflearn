# 機器學習診斷與優化完整筆記：偏差 (Bias)、方差 (Variance) 與系統化調參食譜

## 1. 基本概念

* **高偏差 (High Bias)**：發生在模型無法很好地擬合訓練數據時，通常稱為**欠擬合 (Underfitting)**。
  * *範例*：對非線性數據強行使用線性回歸擬合。
* **高方差 (High Variance)**：發生在模型過度擬合訓練數據，導致無法泛化到新數據時，稱為**過擬合 (Overfitting)**。
  * *範例*：使用過於複雜的分類器去捕捉數據中的雜訊。
* **深度學習時代的變革**：在傳統機器學習中常討論「偏差-方差權衡 (Bias-Variance Tradeoff)」，但在深度學習領域，這種權衡關係變得較不明顯（可同時透過加大網路與增加數據來獨立降低偏差與方差）。

---

## 2. 診斷指標與評估流程

診斷的主要工具是觀察 **訓練集誤差 (Training set error)** 與 **開發集誤差 (Dev set error)** 的數值對比。

### 診斷案例表 (假設人類 / 貝葉斯誤差接近 0%)

| 訓練集誤差 | 開發集誤差 | 診斷結果 | 說明 |
| :---: | :---: | :---: | :--- |
| **1%** | **11%** | **高方差 (High Variance)** | 模型在訓練集表現優異，但無法泛化到開發集（差距達 10%）。 |
| **15%** | **16%** | **高偏差 (High Bias)** | 模型甚至無法擬合訓練集，儘管訓練集與開發集的差距不大。 |
| **15%** | **30%** | **高偏差 & 高方差** | 最糟的情況，既沒擬合好訓練集，泛化表現也極差。 |
| **0.5%** | **1%** | **低偏差 & 低方差** | 理想狀態，模型表現良好且泛化穩定。 |

### 重要前提：貝葉斯誤差 (Bayes Error)

* 上述診斷是建立在「最優誤差（貝葉斯誤差）接近 0%」的假設上。
* **基準線判斷**：如果貝葉斯誤差較高（例如圖像過於模糊，連人類專家辨識的誤差率也高達 15%），那麼 15% 的訓練誤差應被視為「低偏差」，因為這已接近理論最優上限。
* **泛化能力評估**：透過觀察誤差從訓練集到開發集增加了多少（Dev Error - Train Error），可以衡量方差問題的嚴重程度。

### 特殊情況：高偏差且高方差 (High Bias & High Variance)

* 這種情況在二維空間中較難想像，但在**高維度數據**中非常常見。
* **特徵**：模型在大部分區域表現出「欠擬合」（例如大範圍使用線性決策邊界），但在特定數據點或局部區域又表現出「過擬合」（過度靈活地去擬合某些雜訊點）。

## 3. 系統化優化食譜 (Basic Recipe for Machine Learning)

在訓練初始模型後，必須系統化地判斷問題所在，並執行對應解決方案，因為針對偏差與方差的解決手段截然不同。

```text
[開始訓練模型] ──> 訓練集表現良好？ ──(否: 高偏差)──> 加大網路 / 延長訓練 / 優化架構 ──┐
                         │                                                       │
                       (是)                                                      │
                         ▼                                                       │
                 開發集表現良好？ ──(否: 高方差)──> 增加數據 / 加上正則化 / 優化架構 ──┘
                         │
                       (是)
                         ▼
                   [完成模型部署]
```

### 步驟一：處理高偏差（欠擬合）
若模型連訓練集都無法良好擬合，應反覆嘗試以下方法，直到訓練集表現達標：
* **採用更大的網路**：增加隱藏層數（Layers）或隱藏單元（Units）。加大網路規模幾乎總是能有效降低偏差。
* **延長訓練時間**：增加訓練的迭代次數（Epochs），或改用更先進的優化算法（如 Adam、RMSprop）。
* **尋找更合適的網路架構**：選擇更貼合該問題領域的架構（如影像採用 CNN，序列數據採用 Transformer/RNN）。

### 步驟二：處理高方差（過擬合）
一旦訓練集誤差符合預期，若開發集表現不佳（無法泛化），則應執行以下對策：
* **獲取更多訓練數據**：這是解決高方差的最佳方式。只要條件允許，增加數據量能顯著提升泛化能力且通常不會損害偏差。
* **加入正則化 (Regularization)**：在無法取得更多數據時的核心技術（如 L2 正則化、Dropout、Data Augmentation），雖可能略微增加偏差，但能大幅抑制過擬合。
* **尋找更合適的網路架構**：部分架構天生具有較好的正則化效益或結構約束。

## 4. 現代深度學習的突破與優勢

* **打破傳統「偏差-方差權衡 (Trade-off)」**：
  在傳統機器學習中，降低偏差往往會導致方差升高，反之亦然。現代深度學習提供了可以「單獨」調控的工具：
  * **單獨降低偏差**：在搭配適當正則化的前提下加大網路規模（幾乎不增加方差）。
  * **單獨降低方差**：收集與補強更多數據（幾乎不增加偏差）。
* **主要的實際限制**：
  在現代深度學習中，訓練大型網路的主要代價在於**計算資源與時間**（Computational Cost），而非演算法層面的性能衰退。只要搭配良好的正則化，規模越大的網路通常表現越好。
