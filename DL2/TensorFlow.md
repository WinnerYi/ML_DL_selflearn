## 1. 課程導引：為什麼選擇 TensorFlow？

在深入複雜的神經網路之前，我們必須先掌握「優化」的核心。本筆記的任務是利用 TensorFlow 最小化一個簡單的二次損失函數：

$$J(w) = w^2 - 10w + 25$$

這個函數其實可以改寫為：

$$J(w) = (w - 5)^2$$

顯而易見，當 $w = 5$ 時，函數值最小。

* **學習視角轉換**：雖然我們可以一眼看出答案，但訓練複雜神經網路的過程與此高度相似。神經網路擁有成千上萬個參數（如 $w$ 與 $b$），我們需要透過 TensorFlow 自動化地進行「求導（Taking derivatives）」，尋找這些參數的最佳值。掌握了這個簡單的二次函數優化，你就能理解訓練大型模型時，系統如何自動尋找損失函數最低點的底層邏輯。
* **準備好了嗎？** 接下來我們將進入程式碼實作階段，看看如何用 TensorFlow 的語法來定義這個問題。

## 2. TensorFlow 程式結構起手式

撰寫 TensorFlow 程式的第一步是環境配置與變數宣告。

### 環境導入與變數定義
在 TensorFlow 中，變數（Variable）是需要被優化的參數。
* **導入模組**：習慣上我們會將 `numpy` 簡寫為 `np`，`tensorflow` 簡寫為 `tf`。
* **定義變數**：使用 `tf.Variable` 定義我們要優化的參數 `w`。
* **關鍵細節：為什麼選擇 `tf.float32`？** 在深度學習中，`tf.float32` 是標準的資料型別。它在計算速度、記憶體佔用與數值精度（Numerical Precision）之間達到了最佳平衡。

### 建構損失函數的兩種方式
TensorFlow 提供底層算子與直觀的運算子重載兩種寫法：

| 比較維度 | 底層算子 (Low-level Ops) | 運算子重載 (Operator Overloading) |
| :--- | :--- | :--- |
| **程式碼範例** | `cost = tf.add(tf.add(w**2, tf.multiply(-10.0, w)), 25.0)` | `cost = w**2 - 10*w + 25` |
| **可讀性** | 較為冗長，邏輯層次較多 | 直觀、簡潔，如同撰寫數學公式 |
| **建議用法** | 用於需要精細控制算子行為時 | 日常開發與模型建構的首選 |

> **重點提示**：只要將 `w` 宣告為 `tf.Variable`，TensorFlow 就會自動處理運算子重載，讓開發者能以最自然的方式描述數學模型。

定義完函數後，計算圖已經在後台悄悄建構完成。現在，我們需要啟動 TensorFlow 的執行引擎來運轉它。

## 3. Session 執行機制與資源管理

在 TensorFlow 1.x 的架構中，定義好運算邏輯（圖）後，必須透過 `Session` 才能啟動運算。

### 標準化流程步驟
啟動 TensorFlow 運算的關鍵三步驟：
1. **初始化變數**：建立初始化算子 `init = tf.global_variables_initializer()`。
2. **建立 Session**：使用 `tf.Session()` 創建執行環境。
3. **執行初始化運算**：呼叫 `session.run(init)`。

> **導師提醒**：在 TensorFlow 中，變數必須被顯式初始化，否則計算圖雖有結構，卻沒有任何起始數值可以運算。

### 資源管理優化：使用 `with` 語法
開發者通常會在以下兩種語法中選擇：

**方式 A：傳統手動管理**
```python
sess = tf.Session()
sess.run(init)
print(sess.run(w))
# 必須記得手動關閉，否則佔用資源
sess.close()
```

**方式 B：推薦的 `with` 語法（自動化管理）**
```python
with tf.Session() as sess:
    sess.run(init)
    print(sess.run(w))
```

* **優勢**：`with` 語法在 Python 中具備更好的異常處理機制。即便程式運行中發生錯誤，它也能確保 Session 被正確關閉並釋放記憶體資源，避免洩漏。

## 4. 梯度下降優化器的實踐

優化器負責沿著梯度的反方向調整參數，是自動化訓練的核心。
* **優化器配置**：使用 `tf.train.GradientDescentOptimizer`，設定學習率（Learning Rate）為 `0.01`。
* **目標設定**：`optimizer.minimize(cost)` 會自動計算梯度並更新 `w`。

### 收斂過程的數值觀察
當我們連續執行 1000 次優化步驟後，可以觀察到 $w$ 的收斂路徑：
* `[Step 0 - 初始狀態]` $
ightarrow w = 0$
* `[Step 1 - 跨出首步]` $
ightarrow w = 0.1$ （梯度引導 $w$ 開始向 5 靠近）
* `[Step 1000 - 最終收斂]` $
ightarrow w = 4.9999$

這證明了 TensorFlow 成功地引導參數極度接近理論最優解 5。

## 5. 動態資料注入：Placeholder 與 Feed Dict

在訓練真實的神經網路時，訓練集（$X$ 與 $y$）會隨著每個批次（Batch）更換，這時就需要 `tf.placeholder`。
* **預留位置 (Placeholder)**：它像是一個「空容器」，定義了資料的型別與形狀，但在執行時才透過 `feed_dict` 填入具體數值。
* **數據與函數的解耦**：我們將二次函數的係數 `[1, -10, 25]` 定義為一個 $3 	imes 1$ 的矩陣 `coefficients`。

### 與 Mini-batch 的關聯
Placeholder 對於 **Mini-batch 梯度下降** 至關重要。你只需定義一次模型架構，接著在迴圈中透過 `feed_dict={x: data_batch}` 不斷注入不同的數據子集，即可完成大規模數據的訓練。

### 靈活性驗證
若想優化另一個函數 $J(w) = (w - 10)^2$，只需將傳入的 `x` 改為 `[1, -20, 100]`，$w$ 就會自動收斂至 10，完全不需要修改模型結構。

## 6. 核心機制：計算圖 (Computation Graph)

TensorFlow 的強大在於它將開發者從複雜的微積分中解放出來。
* **自動化反向傳播 (Backprop)**：你只需定義前向傳播 (Forward Prop) 的邏輯（例如如何從輸入計算出 Cost）。TensorFlow 會自動建構一幅計算圖，因為它內建了所有基礎算子（如 `add`, `multiply`, `square`）的求導法則，它能透過連鎖律自動推導出複雜函數的梯度。
* **高度彈性的架構**：由於優化過程已模組化，將 `GradientDescentOptimizer` 替換為更先進的 `AdamOptimizer` 僅需修改一行程式碼。這種極高的彈性是現代框架的核心價值。

### 標記慣例對比
在查看官方文件時，你會遇到兩種圖示風格：
1. **數值節點法**：節點標註的是變數本身（如 $w^2$）。
2. **算子節點法 (官方標準)**：節點代表「運算操作」（如 `square`, `add`）。這種方式更精確地描述了資料如何經過各個運算單元被處理。
