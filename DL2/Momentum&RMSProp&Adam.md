# 深度學習優化演算法學習筆記：Momentum, RMSProp 與 Adam

---

## 一、 動量梯度下降法（Gradient Descent with Momentum）

### 1. 核心概念
動量梯度下降法是一種幾乎總是比標準梯度下降法更快的優化算法。其核心思想是計算梯度的**指數加權平均值（Exponentially Weighted Average）**，並使用這個平均值來更新權重，而非直接使用當前的梯度。

### 2. 標準梯度下降的問題
* **震盪現象**：在優化成本函數時，若其輪廓呈現細長橢圓形（如碗狀），標準梯度下降在垂直軸上會產生大量的上下震盪。
* **限制學習率**：這些上下震盪會減慢前進速度，並限制了使用較大學習率（Learning Rate $\alpha$）的可能性（若學習率過大，可能會導致過度偏差、偏離甚至發散）。
* **優化目標**：理想上，我們希望在垂直方向減緩震盪，但在水平方向快速移動以逼近最小值。

### 3. 運作原理與公式
在每次迭代 $t$ 中，計算當前 mini-batch 的導數 $dW$ 和 $db$（若使用 Batch 梯度下降，則 mini-batch 即為整個訓練集）：

1. **計算移動平均（動量速度）**：
   $$v_{dW} = \beta v_{dW} + (1 - \beta) dW$$
   $$v_{db} = \beta v_{db} + (1 - \beta) db$$

2. **更新權重**：
   $$W = W - \alpha v_{dW}$$
   $$b = b - \alpha v_{db}$$

> **註**$:v_{dW}$ 和 $v_{db}$ 初始化為與 $W$ 和 $b$ 相同維度的零矩陣與零向量。

### 4. 為什麼能平抑震盪？
* **垂直方向**：由於梯度的正負號經常相反，在計算移動平均時，正負數相加會趨近於零，從而大幅減緩了垂直方向的震盪步伐。
* **水平方向**：所有導數都指向同一個方向（右側，即最小值的方向），因此水平方向的平均值依然很大。
* **結果**：演算法能夠以更直接、震盪更小（更平滑）的方式，快速朝最小值前進。

### 5. 物理直覺（滾動小球的類比）
將成本函數想像成一個碗狀的山谷：
* **導數 ($dW, db$)**：提供了小球滾下山坡的加速度。
* **動量項 ($v_{dW}, v_{db}$)**：代表小球的速度。
* **超參數 $\beta$**（介於 $0$ 到 $1$ 之間）：扮演摩擦力的角色，防止小球在沒有限制的情況下不斷加速。
* 小球在滾動時會不斷累積動量，因此能越滾越快。

### 6. 實作細節與超參數設定
* **兩個超參數**：學習率 $\alpha$ 以及控制指數加權平均的 $\beta$。
* **$\beta$ 的選擇**：最常用的推薦數值為 **0.9**（相當於平均過去約 10 次迭代的梯度），在實務上非常穩健。
* **偏差修正（Bias Correction）**：實務上通常不會對 $v_{dW}$ 和 $v_{db}$ 進行偏差修正（即除以 $1 - \beta^t$），因為在 10 次迭代後移動平均就已暖身（warmed up）完畢，偏差影響極小。
* **公式的另一種版本**：部分文獻會省略 $(1 - \beta)$ 項（即 $v_{dW} = \beta v_{dW} + dW$）。這會使 $v_{dW}$ 被放大 $\frac{1}{1-\beta}$ 倍，導致調整 $\beta$ 時必須連帶重新調整學習率 $\alpha$。因此，使用含有 $(1 - \beta)$ 項的原始公式更為直覺，調整 $\beta$ 時比較不會影響到學習率的設定。

## 二、 RMSProp 演算法（Root Mean Square Prop）

### 1. 核心目的與直觀理解
* **消除特定方向的振盪（Oscillations）**：在梯度下降過程中，常會遇到在某些維度（例如偏置項 $b$ 所在的垂直方向）產生巨大的上下振盪，而在我們真正想要前進的維度（例如權重 $W$ 所在的水平方向）進展緩慢。
* **動態調整更新幅度**：RMSProp 的運作原理是減緩振盪維度的學習速度，同時維持（或加速）目標推進維度的學習速度。
* **允許更大的學習率**：由於振盪被有效抑制，我們可以使用更大的學習率 $\alpha$，進而大幅提升演算法的整體訓練速度，而不用擔心在垂直方向發生發散。

### 2. 演算法數學原理（以迭代 $t$ 為例）
在每次迭代中，先在當前的 mini-batch 上計算導數 $dW$ 與 $db$，接著執行：

#### 步驟一：計算梯度平方的指數加權平均
計算各參數梯度的平方，並維護其指數加權平均值（元素級平方運算）：
$$s_{dW} = \beta_2 s_{dW} + (1 - \beta_2) (dW)^2$$
$$s_{db} = \beta_2 s_{db} + (1 - \beta_2) (db)^2$$
*(備註：為了避免與 Momentum 中的超參數混淆，此處通常將 RMSProp 的超參數記為 $\beta_2$)*

#### 步驟二：更新參數
在更新參數時，將梯度除以剛才計算出的加權平均平方根：
$$W = W - \frac{\alpha}{\sqrt{s_{dW}} + \epsilon} dW$$
$$b = b - \frac{\alpha}{\sqrt{s_{db}} + \epsilon} db$$
*(其中 $\epsilon$ 是一個極小的常數，用以確保數值穩定性、防止分母為 zero。實務上合理的預設值通常為 $10^{-8}$)*

### 3. 為什麼這能抑制振盪？
* **陡峭（振盪）的方向**：在函數坡度非常陡峭的維度（如 $b$ 方向），其導數 $db$ 很大，因此 $(db)^2$ 也很大，導致其累計的指數加權平均值 $s_{db}$ 變得非常大。在參數更新時，因為除以了一個很大的 $\sqrt{s_{db}}$，更新幅度會被大幅削弱（Damp out），進而平抑該方向的振盪。
* **平緩（前進）的方向**：在函數坡度較為平緩、我們希望快速推進的維度（如 $W$ 方向），其導數 $dW$ 較小，因此 $(dW)^2$ 較小，累計的 $s_{dW}$ 也較小。更新參數時除以較小的 $\sqrt{s_{dW}}$，更新幅度受到的限制很小，使得該方向能繼續保持快速推進。

### 4. 歷史趣聞（Fun Fact）
* **非學術論文出身**：RMSProp 最初並不是發表在正式的學術研究論文中，而是由 Geoff Hinton 在 Coursera 線上課程中講授時首次提出。
* **意外廣為流傳**：雖然 Coursera 當初並非旨在發表新學術成果，但該演算法卻藉由這堂課迅速走紅，並在深度學習社群中被廣泛應用。

## 三、 Adam 優化演算法（Adaptive Moment Estimation）

### 1. 基本概念與背景
* **優化演算法的突破**：許多研究人員提出的優化演算法往往只能在少數特定問題上發揮作用，難以推廣至各種不同的神經網路架構。
* **廣泛實證有效**：Adam 與 RMSProp 是少數經受住考驗、被證實能在廣泛的神經網路架構中極為有效運作的演算法之一。
* **結合兩者優勢**：其核心思想非常簡單，即將**動量（Momentum）**與 **RMSProp** 兩種優化技術相結合。

### 2. 數學更新公式與步驟

#### 步驟一：初始化
設定動量項（一階動量）與平方項（二階動量）的初始值為 0：
$$v_{dW} = 0, \quad v_{db} = 0$$
$$s_{dW} = 0, \quad s_{db} = 0$$

#### 步驟二：在每次迭代（Iteration $t$）中計算
1. **計算梯度**：使用當前的 mini-batch 計算導數（梯度）$dW$ 與 $db$。
2. **Momentum 更新**（使用超參數 $\beta_1$ 計算導數的指數加權平均）：
   $$v_{dW} = \beta_1 v_{dW} + (1 - \beta_1) dW$$
   $$v_{db} = \beta_1 v_{db} + (1 - \beta_1) db$$
3. **RMSprop 更新**（使用超參數 $\beta_2$ 計算導數平方的指數加權平均）：
   $$s_{dW} = \beta_2 s_{dW} + (1 - \beta_2) (dW)^2$$
   $$s_{db} = \beta_2 s_{db} + (1 - \beta_2) (db)^2$$

#### 步驟三：偏差修正（Bias Correction）
由於 $v$ 和 $s$ 初始化為 0，在初期迭代時數值會偏向 0。為了消除此偏差，會加入偏差修正步驟（$t$ 為當前迭代次數）：
$$v_{dW}^{\text{corrected}} = \frac{v_{dW}}{1 - \beta_1^t}, \quad v_{db}^{\text{corrected}} = \frac{v_{db}}{1 - \beta_1^t}$$
$$s_{dW}^{\text{corrected}} = \frac{s_{dW}}{1 - \beta_2^t}, \quad s_{db}^{\text{corrected}} = \frac{s_{db}}{1 - \beta_2^t}$$

#### 步驟四：更新權重與偏差
利用修正後的動量與平方項更新參數：
$$W = W - \alpha \frac{v_{dW}^{\text{corrected}}}{\sqrt{s_{dW}^{\text{corrected}}} + \epsilon}$$
$$b = b - \alpha \frac{v_{db}^{\text{corrected}}}{\sqrt{s_{db}^{\text{corrected}}} + \epsilon}$$

### 3. 超參數預設值與調整建議
* **學習率（Learning Rate）$\alpha$**：最關鍵的超參數。依然非常重要且通常需要進行調校。需嘗試不同的數值範圍，以找出最適合當前神經網路的設定。
* **$\beta_1$**：預設推薦值為 **0.9**。用於計算導數的一階動量（移動平均）。
* **$\beta_2$**：論文作者推薦值為 **0.999**。用於計算導數平方的二階移動加權平均。
* **$\epsilon$**：論文作者推薦值為 **$10^{-8}$**。主要用於防止分母為零，對演算法效能影響極小，通常完全不需要調整。

> **💡 實務建議**：在實際應用中，通常會直接採用 $\beta_1$、$\beta_2$ 和 $\epsilon$ 的預設推薦值，而將心力集中於調校學習率 $\alpha$。

### 4. 命名由來
* **Adam** 全名為 **Adaptive Moment Estimation**（自適應矩估計）。
* **第一矩（First Moment）**：$\beta_1$ 用於計算導數的平均值。
* **第二矩（Second Moment）**：$\beta_2$ 用於計算導數平方的指數加權平均。
* **自適應**：演算法會自適應地利用這兩個矩來調整學習步長，因而得名。
