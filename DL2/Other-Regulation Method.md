# 資料增強 (Data Augmentation) 與早停法 (Early Stopping) 筆記

本筆記整理兩種用於減少神經網路**過擬合 (Overfitting)** 的正規化 (Regularization) 技術。

---

## 1. 資料增強 (Data Augmentation)

當模型發生過擬合，且獲取全新真實訓練數據的成本過高或不可行時，資料增強是一個非常有效的解決方案。

* **核心概念**：透過對現有數據（如圖像）進行幾何變換或圖像處理，人工合成新的訓練樣本，藉此增加數據的多樣性。
* **常見手段**：
  * **水平翻轉 (Horizontal Flipping)**：最簡單且常用的增強方式之一（例如：將貓的圖像水平翻轉後，模型仍應將其識別為貓）。
  * **隨機裁剪與扭曲 (Random Crops and Distortions)**：包含隨機旋轉、縮放與幾何扭曲等。
  * **應用於光學字元辨識 (OCR)**：對數字或文字進行微小旋轉或輕微扭曲。*注意：實務上建議使用微小形變，避免誇張扭曲導致語意改變。*
* **效果與成本**：
  * **優點**：獲取成本幾乎為零（僅需額外算力）。
  * **效果**：雖然「合成樣本」所包含的獨立資訊量略低於真實新樣本，但能有效正規化模型並降低**變異數 (Variance)**。

---

## 2. 早停法 (Early Stopping)

早停法是另一種廣泛應用於防止過擬合的技術，其核心在於訓練過程中持續監控**開發集 (Dev Set / Validation Set)** 的表現。

* **操作方式**：
  1. 同時記錄並繪製訓練誤差（或成本函數 $J$）與開發集誤差隨迭代次數（Epochs/Iterations）變化的曲線。
  2. **訓練誤差**：通常隨迭代次數增加而持續下降。
  3. **開發集誤差**：初期會下降，但達到某個臨界點後會開始上升（代表模型開始過擬合）。
  4. **停止時機**：在開發集誤差達到**最低點**時立即停止訓練。
* **運作原理**：
  * 訓練初期，權重參數 $W$ 通常被初始化為接近 0 的小隨機數。
  * 隨着梯度下降迭代次數增加，$W$ 的範數（大小）會逐漸變大。
  * 透過早停法，可以將 $W$ 限制在中等規模的大小，達到類似 **L2 正規化** 限制權重大小的效果。

---

## 3. 正交化 (Orthogonalization) 的考量與比較

在機器學習系統設計中，**正交化 (Orthogonalization)** 是一個重要的原則，意即「希望一項工具只專注解決一個特定問題，彼此互不干擾」。

| 評比維度 | 早停法 (Early Stopping) | L2 正規化 (L2 Regularization) |
| :--- | :--- | :--- |
| **正交性 (Orthogonalization)** | **較差（耦合）**<br>同時影響「優化成本函數 $J$」與「防止過擬合（降低變異）」。停止訓練時，成本函數 $J$ 未必達到極小值。 | **良好（正交）**<br>可讓梯度下降持續優化 $J$ 至極限，並透過獨立調整超參數 $\lambda$ 來專注處理過擬合問題。 |
| **計算成本 (Computational Cost)** | **極低**<br>只需執行**一次**梯度下降訓練過程，即可觀察到權重 $W$ 由小到大的變化並找到最佳停止點。 | **較高**<br>需要針對多組不同的 $\lambda$ 超參數進行多次完整訓練與網格搜尋 (Grid Search)。 |
| **實務選擇與總結** | 雖然在理論上使用 L2 正規化能保持優化與正規化的正交性，但在計算資源有限的情況下，**早停法**仍是一個高效且廣泛應用的正規化工具。 |
