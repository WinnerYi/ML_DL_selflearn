## 一、 學習率衰減 (Learning Rate Decay)

### 1. 為什麼需要學習率衰減？
* **解決 Mini-batch 梯度下降的震盪問題**：在使用較小 mini-batch（如 64 或 128 個樣本）時，因為不同 mini-batch 的數據存在噪聲，若使用固定的學習率 $\alpha$，演算法在接近全局或局部最小值時會不斷徘徊震盪，無法精確收斂。
* **直覺與機制**：
  * **訓練初期**：學習率 $\alpha$ 較大，允許演算法快速學習並採取較大的步長前進。
  * **訓練後期**：隨著 $\alpha$ 逐漸減小，步長變慢且變小，使演算法能在最小值周圍更緊密的區域內收斂，避免大幅漂移。

### 2. 常見實作公式與方法
> **註**：在實作中，一個 「Epoch」 代表完整遍歷一次訓練數據。

#### (1) 基礎衰減 (Standard Decay)
$$\alpha = \frac{1}{1 + \mathtt{decay\_rate} \times \mathtt{epoch\_num}} \alpha_0$$
* **超參數**：$\alpha_0$（初始學習率）、$\text{decay\_rate}$（衰減率，控制衰減速度）。
* **計算範例**（若 $\alpha_0 = 0.2$ 且 $\text{decay\_rate} = 1$）：
  * Epoch 1: $\alpha = 0.1$
  * Epoch 2: $\alpha \approx 0.67 \times \alpha_0 = 0.133$（逐字稿原始數值標示為 $0.67$）
  * Epoch 3: $\alpha = 0.05$（即 $\frac{0.2}{1 + 3} = 0.05$）
  * Epoch 4: $\alpha = 0.04$

#### (2) 指數衰減 (Exponential Decay)
$$\alpha = 0.95^{\mathtt{epoch\_num}} \times \alpha_0$$
* 使用小於 1 的常數（如 0.95）作為底數，使學習率隨 Epoch 增加呈指數級快速下降。

#### (3) 平方根衰減 (Square Root Decay)
$$\alpha = \frac{\text{constant}}{\sqrt{\mathtt{epoch\_num}}} \alpha_0 \quad \text{或} \quad \alpha = \frac{\text{constant}}{\sqrt{t}} \alpha_0$$
* 學習率與時間（Epoch 數或 mini-batch 編號 $t$）的平方根成反比。

#### (4) 離散階梯式衰減 (Discrete Staircase Decay)
* 在特定訓練步數（Steps）內維持相同學習率，每隔固定時間就將學習率折半（如乘以 0.5），呈現階梯狀下降。

#### (5) 手動衰減 (Manual Decay)
* **適用場景**：模型訓練時間極長（數小時至數天），且一次只訓練極少數模型。
* **做法**：研究人員即時觀察訓練過程（如 Loss 曲線），當發現學習變慢時，手動調降學習率 $\alpha$。

### 3. 超參數選擇優先順序建議
* **調參優先級較低**：雖然學習率衰減能加速收斂，但在超參數調校清單中順序相對靠後。
* **實務建議**：訓練初期先將 $\alpha$ 設為固定值，專注於調出最佳固定值。

## 二、 超參數重要性與搜尋策略

### 1. 超參數的重要性分級 (Importance Grading)
| 優先級梯隊 | 超參數項目 | 說明 / 預設值建議 |
| :--- | :--- | :--- |
| **第一優先（最重要）** | 學習率 $\alpha$ (Learning Rate) | 最關鍵、必須優先調校的超參數 |
| **第二優先（次要）** | 動量項 $\beta$ (Momentum)<br>Mini-batch 大小<br>隱藏單元數量 (Hidden units) | $\beta$ 實務預設值通常為 0.9；Mini-batch 用於優化計算效率 |
| **第三優先（再次之）** | 神經網路層數 (Number of layers)<br>學習率衰減 (Learning Rate Decay) | 有時會帶來顯著影響，但優先度較後 |
| **幾乎無需調整** | Adam 最佳化超參數 ($\beta_1, \beta_2, \epsilon$) | 直接採用預設值：$\beta_1=0.9, \beta_2=0.999, \epsilon=10^{-8}$ |

> 💡 **備註**：此分級為實務經驗總結，非絕對規則，不同領域與經驗可能略有差異。

---

### 2. 隨機取樣 (Random Sampling) vs. 網格搜索 (Grid Search)

#### 網格搜索 (Grid Search) 的局限性
* 傳統機器學習常在二維空間建立 $5 \times 5$ 網格測試 25 個點。
* **深度學習不推薦**：無法預知哪一個超參數影響較大。若超參數 1（學習率 $\alpha$）極重要，而超參數 2（$\epsilon$）幾乎無影響，網格搜索雖然訓練了 25 個模型，實質上只嘗試了 5 個不同的 $\alpha$ 值。

#### 隨機取樣 (Random Sampling) 的優勢
* 深度學習**強烈推薦**在搜尋空間內隨機採樣。
* 同樣訓練 25 個模型，隨機取樣能探索 25 個完全不同的 $\alpha$ 值，大幅提升找到最優解的機率。高維空間（三維以上）更能豐富且全面地覆蓋探索區域。

---

### 3. 由粗到細的搜尋策略 (Coarse-to-Fine Search Scheme)
1. **初步粗篩 (Coarse Search)**：在整個超參數空間進行隨機採樣，評估整體表現。
2. **鎖定區域並細化 (Fine Search)**：找到表現優異的隨機點後，縮小範圍（Zoom in）至該子區域。
3. **密集採樣**：在縮小後的子區域進行更密集的隨機採樣，集中計算資源。
4. **確定最優值**：根據模型在訓練集或開發集（Validation/Dev set）上的表現，挑選最佳設定。

* **核心結論**：放棄網格搜索，一律採用隨機取樣，並視情況搭配由粗到細搜尋。

## 三、 超參數搜尋空間的適當尺度採樣

採樣時不可盲目使用「線性均勻隨機採樣」，須針對超參數特性選擇 **適當尺度 (Scale)**。

### 1. 適用線性均勻隨機採樣 (Linear Uniform Scale) 的場景
* **特性**：合理取值在數線上均勻分佈。
* **範例**：
  * **隱藏單元數 $n^{[l]}$**：如範圍在 50 到 100 之間，直接進行線性均勻採樣。
  * **網路層數 $L$**：如範圍在 2 到 4 之間，線性採樣或直接網格評估 2, 3, 4。

---

### 2. 對數尺度採樣 (Logarithmic Scale) — 以學習率 $\alpha$ 為例

#### 為什麼學習率 $\alpha$ 不適合線性採樣？
* 假設搜尋範圍 $\alpha \in [0.0001, 1]$：
  * **線性採樣缺點**：約 90% 的隨機樣本會落在 $[0.1, 1]$ 之間。
  * **資源浪費**：90% 的資源浪費在大數值區間，僅 10% 資源探索 $[0.0001, 0.1]$（包含 $0.001, 0.01$ 等關鍵數量級）。
  * **正確做法**：採用對數尺度，讓每個數量級區間（如 $10^{-4} \to 10^{-3}$、$10^{-3} \to 10^{-2}$）獲得同等比例的搜尋資源。

#### 對數採樣數學步驟與 Python 實作
1. **求對數邊界**：$a = \log_{10}(\text{low})$, $b = \log_{10}(\text{high})$
   * 以 $\alpha \in [0.0001, 1]$ 為例：$a = \log_{10}(0.0001) = -4$，$b = \log_{10}(1) = 0$。
2. **均勻採樣 $r$**：在 $[a, b]$ 區間（即 $[-4, 0]$）隨機均勻採樣實數 $r$。
3. **計算超參數**：$\alpha = 10^r$。

```python
import numpy as np

# 1. 定義搜尋範圍的對數邊界
a = -4  # 對應 0.0001 (10^-4)
b = 0   # 對應 1.0    (10^0)

# 2. 在 [a, b] 之間進行隨機均勻採樣得到 r
r = a + (b - a) * np.random.rand()

# 3. 計算最終的學習率 alpha
alpha = 10 ** r

print(f"採樣得到的 r: {r:.4f}")
print(f"採樣得到的學習率 alpha: {alpha:.6f}")
```

---

### 3. 指數加權平均超參數 $\beta$ 的特殊採樣

#### 敏感度問題 (Sensitivity)
指數加權平均代表平均過去約 $\frac{1}{1 - \beta}$ 個樣本的數據：
* $\beta = 0.9 \implies \frac{1}{1-0.9} = 10$ 天
* $\beta = 0.99 \implies \frac{1}{1-0.99} = 100$ 天
* $\beta = 0.999 \implies \frac{1}{1-0.999} = 1000$ 天

當 $\beta$ 接近 1 時，公式對微小變化**極度敏感**：
* $\beta$ 從 $0.9 \to 0.9005$：結果幾乎無影響。
* $\beta$ 從 $0.999 \to 0.9995$：微小差距 $0.0005$ 使平均天數從 **1000 天翻倍至 2000 天**！

#### 採樣公式與 Python 實作
對 $1 - \beta$ 進行對數尺度採樣：
* 若 $\beta \in [0.9, 0.999]$，則 $1 - \beta \in [0.1, 0.001]$（即 $10^{-1} \to 10^{-3}$）。
* 邊界：$a = \log_{10}(0.001) = -3$，$b = \log_{10}(0.1) = -1$。
* 採樣 $r \in [-3, -1]$，計算 $1 - \beta = 10^r \implies \beta = 1 - 10^r$。

```python
import numpy as np

# 1. 定義 1-beta 的對數邊界值
a = -3  # 對應 1-beta = 0.001 (即 beta = 0.999)
b = -1  # 對應 1-beta = 0.1   (即 beta = 0.9)

# 2. 在 [-3, -1] 之間隨機均勻採樣 r
r = a + (b - a) * np.random.rand()

# 3. 計算最終的 beta 值
beta = 1 - 10 ** r

print(f"採樣得到的 r: {r:.4f}")
print(f"計算得到的 1-beta: {10**r:.6f}")
print(f"最終採樣得到的 beta: {beta:.6f}")
```

## 四、 超參數調校實務策略：貓熊 vs. 魚子醬

### 1. 領域轉移與直覺時效性
* **跨領域借鑒 (Cross-fertilization)**：不同領域（CV、Speech、NLP）的超參數直覺可互相轉移（如 CNN 與 ResNets 轉移至語音與 NLP），閱讀跨領域論文能激發創新思維。
* **直覺的時效性 (Intuitions get stale)**：隨著時間推移（如數個月），數據分佈可能改變或硬體升級，導致舊的超參數失效。建議**每隔幾個月重新評估**超參數。

---

### 2. 兩大搜尋策略比較

| 比較項目 | 貓熊策略 (Panda Approach) | 魚子醬策略 (Caviar Strategy) |
| :--- | :--- | :--- |
| **別名** | 照料單一模型 (Babysitting one model) | 並行訓練多個模型 (Training many models in parallel) |
| **適用場景** | 資料量龐大，但計算資源（CPU/GPU）有限 | 擁有充足計算資源，能同時並行訓練許多模型 |
| **執行方式** | 每天觀察單一模型的學習曲線（Cost / Dev Error），手動微調參數（如調大/調小 $\alpha$、調整 $\beta$） | 同時啟動多個不同超參數設定的模型獨立運行，繪製學習曲線後直接挑選最佳者 |
| **特點** | 精心照顧單一模型，時間跨度數天至數週 | 嘗試大量組合，快速篩選最優解 |
| **命名典故** | 貓熊一次通常只生一胎，投入極大精力撫育幼崽 | 魚類單季產卵數億顆，不對個體投入過多關注，靠數量確保存活 |

### 3. 策略選擇原則
* **計算資源**為最核心決定因素；資源充足時首選魚子醬策略。
* **領域限制**：如大型線上廣告系統或超大型 CV 模型，因模型與資料量極巨大，難以並行訓練，多採用貓熊策略。
* **靈活性**：貓熊策略使用者可以在照顧完一個模型並取得結果後，重新初始化並照顧下一個新模型。
