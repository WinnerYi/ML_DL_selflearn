# 殘差網路 (ResNets) 核心觀念學習筆記

---

## 1. 為什麼需要殘差網路 (ResNet)？

### 1.1 深層網路的訓練困境
在傳統的神經網路（稱為**普通網路，Plain Network**）中，理論上網路層數越深，模型的表達能力越強，訓練集上的表現應該要越來越好。然而在實際訓練中，極深的普通網路面臨以下瓶頸：
* **梯度消失與爆炸 (Vanishing / Exploding Gradients)**：反向傳播過程中，梯度在多層傳播後容易呈指數級衰減或暴增，導致前端網路層無法有效更新參數。
* **退化問題 (Degradation Problem)**：當普通網路的層數增加到一定程度後，訓練誤差不降反升（並非由過擬合引起，而是極難透過梯度下降等優化算法進行訓練）。

### 1.2 ResNet 的解決方案
ResNet 透過導入 **跳躍連接 (Skip Connections)** 或稱 **捷徑 (Shortcuts)**，將某一層的激活值（Activation）跨層直接傳送至更深處。
* **效益**：顯著緩解梯度消失問題，使得訓練深度極高（如 100 層甚至高達 1000 層）的神經網路成為可能，且不會造成效能退化。

## 2. 殘差區塊 (Residual Block) 的結構與數學

殘差網路由許多個「殘差區塊 (Residual Block)」堆疊而成。

```
              ┌───────────────────────────┐ (捷徑 Shortcut)
              │                           │
              ▼                           │
a[l] ───► [ Layer l+1 ] ───► z[l+1] ──► [ ReLU ] ──► a[l+1] ──► [ Layer l+2 ] ──► z[l+2] ──► ( + ) ──► [ ReLU ] ──► a[l+2]
                                                                                            ▲
                                                                                            │
                                                                                            └────────┘
```

### 2.1 普通網路（主路徑 Main Path）的計算流程
在未加入捷徑的普通路徑中，資訊從 $a^{[l]}$ 傳遞至 $a^{[l+2]}$ 的計算如下：
1. **第一層線性運算**：
   $$z^{[l+1]} = W^{[l+1]} a^{[l]} + b^{[l+1]}$$
2. **第一層非線性激活 (ReLU)**：
   $$a^{[l+1]} = g(z^{[l+1]})$$
3. **第二層線性運算**：
   $$z^{[l+2]} = W^{[l+2]} a^{[l+1]} + b^{[l+2]}$$
4. **第二層非線性激活**：
   $$a^{[l+2]} = g(z^{[l+2]})$$

### 2.2 殘差區塊（捷徑/跳躍連接）的修正
殘差區塊將 $a^{[l]}$ 直接「快速前送 (Fast Forward)」，在套用第二次 ReLU 激活函數之前，將其直接相加：
$$\mathbf{a^{[l+2]} = g(z^{[l+2]} + a^{[l]})}$$

* **結構特點**：$a^{[l]}$ 注入的時間點位於第二次線性運算（$z^{[l+2]}$）之後、非線性激活（ReLU）之前。
* **關鍵作用**：迫使網路層學習殘差映射 $F(a^{[l]}) = z^{[l+2]}$，而非直接擬合目標映射。

## 3. 殘差區塊學會「恆等函數 (Identity Function)」的原理

ResNet 能夠保證「增加深度絕不損害效能」的核心數學原因，在於其極易學習到**恆等函數**（即 $a^{[l+2]} = a^{[l]}$）。

### 3.1 數學推導
假設網路普遍採用 **ReLU 激活函數**，因此所有隱藏層激活值皆為非負數（$a \ge 0$）：

1. 殘差區塊公式：
   $$a^{[l+2]} = g(z^{[l+2]} + a^{[l]}) = g(W^{[l+2]} a^{[l+1]} + b^{[l+2]} + a^{[l]})$$
2. 在訓練過程中使用 **L2 正則化（權重衰減，Weight Decay）** 時，會驅使權重與偏置趨近於零：
   $$W^{[l+2]}  pprox 0, \quad b^{[l+2]}  pprox 0$$
3. 代入公式後簡化為：
   $$a^{[l+2]} = g(a^{[l]})$$
4. 由於 $a^{[l]}$ 經過前一層 ReLU 後必定非負（$a^{[l]} \ge 0$），故 $g(a^{[l]}) = a^{[l]}$，最終得到：
   $$\mathbf{a^{[l+2]} = a^{[l]}}$$

### 3.2 意義與結論
* **保底機制**：若某兩層神經網路沒有學到任何有用特徵，權重趨近於 0 時，該區塊會直接發揮「複製（恆等傳遞）」作用，不會拖累網路既有的效能表現。
* **對比普通網路**：普通網路在沒有跳躍連接的情況下，極難透過參數組合剛好湊出恆等函數，因此深層普通網路容易導致訓練誤差上升。

## 4. 維度不一致的處理機制

在進行 $z^{[l+2]} + a^{[l]}$ 的加法運算時，兩者的向量/矩陣維度必須完全一致。

### 4.1 同維卷積 (Same Convolutions)
ResNet 內部大量採用 **Same Convolution**（保持 Padding 與 Stride 設計使輸入與輸出特徵圖尺寸相同），確保多數時候可以直接進行捷徑加法。

### 4.2 維度轉換矩陣 ($W_s$)
當輸入 $a^{[l]}$ 與 $z^{[l+2]}$ 維度不一致時（例如經過 Strided Convolution 或 Channel 數量倍增，如從 128 維變為 256 維），會引入維度轉換矩陣 $W_s$：
$$a^{[l+2]} = g(z^{[l+2]} + W_s a^{[l]})$$

$W_s$ 的兩種類型：
1. **可學習的參數矩陣**：使用 $1 	imes 1$ 卷積層調整 Channel 數量與空間解析度。
2. **固定矩陣**：採用 **零填充 (Zero Padding)** 直接擴充維度。

## 5. 普通網路 (Plain Network) vs. 殘差網路 (ResNet) 比較

| 比較維度 | 普通網路 (Plain Network) | 殘差網路 (ResNet) |
| :--- | :--- | :--- |
| **理論表現** | 隨著層數增加，訓練集表現理論上應更好。 | 與理論一致。 |
| **實際訓練誤差** | 當層數增加到一定程度後，訓練誤差先降低後**回升**（退化問題）。 | 即使網路極深，訓練誤差仍能**持續穩定下降**。 |
| **梯度傳播** | 極深層時容易面臨梯度消失/爆炸。 | 跳躍連接提供梯度回傳的「高速公路」，梯度傳播順暢。 |
| **學習恆等函數** | 極難做到（需精確設置複雜參數）。 | 極易做到（權重衰減至 0 即可實現）。 |
| **層數極限** | 難以有效訓練極深網路（如 >20 層後表現下降）。 | 可成功訓練 **100+ 層**，實驗中甚至可達 1000+ 層。 |

## 6. 影像 ResNet 架構細節 (He et al.)

典型用於影像分類的 ResNet 架構包含以下關鍵元素：
1. **主幹結構**：主要由大量的 $3 \times 3$ Same Convolutions 堆疊組成。
2. **池化層 (Pooling)**：網路中會穿插少量的 Pooling Layer（或 Stride=2 的卷積）來下採樣特徵圖；此時會同步啟用 $W_s$ 矩陣對齊捷徑維度。
3. **尾端輸出**：在所有殘差區塊結束後，接上全局平均池化 (Global Average Pooling)，最後透過一個 **全連接層 (Fully Connected Layer)** 與 **Softmax** 進行類別預測。
