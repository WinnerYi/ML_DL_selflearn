# 神經風格轉換（Neural Style Transfer）重點筆記

## 1. 核心定義與概念

- **定義**：神經風格轉換是卷積神經網路（ConvNets / CNN）近年非常熱門且有趣的應用之一 1。
- **目的**：將一張圖片的內容與另一張圖片的藝術風格相互結合，進而生成一張全新的藝術作品 1。

## 2. 常用符號與標示

在實作神經風格轉換時，通常使用以下符號表示 1：

- **C（Content image）**：內容圖片，即希望保留其主要構圖與物件的照片（例如：景色或建築物照片）1。
- **S（Style image）**：風格圖片，即希望參考其筆觸、色彩與藝術紋理的畫作 1。
- **G（Generated image）**：生成的圖片，即結合了 C 的內容與 S 的風格後所產生的新圖像 1。

# 《深度卷積神經網絡在學習什麼？》重點筆記

本影片主要探討深度卷積神經網路（CNN，以類 AlexNet 架構為例）的各個隱藏層（Hidden Layers）究竟在計算與學習哪些特徵 1。影片內容主要參考自 Matthew Zeiler 與 Rob Fergus 的研究論文《Visualizing and Understanding Convolutional Networks》2。

## 1. 特徵視覺化方法（Visualization Methodology）

### 最大化激活法

將訓練集影像輸入神經網路中，找出能讓特定隱藏單元（Hidden Unit）產生**最大激活值（Maximally Activate）**的圖像區塊（Image Patches）1。

### 感受野（Receptive Field）變化

- **淺層（Layer 1）**：隱藏節點只能看見輸入圖像中非常小的區域 1 3。
- **深層（Deeper Layers）**：隱藏節點能覆蓋並看見較大的圖像區域 4。

## 2. 各層學習特徵演進（Layer-by-Layer Feature Evolution）

### 第 1 層（Layer 1）：簡單基礎特徵

主要偵測極為基礎的視覺元素，如特定方向的邊緣（Edges）、線條與特定顏色／色調 2 3。

- **範例**：特定角度的斜線、垂直線，或是單純的橘色、紅綠混合色塊等 2 3。

### 第 2 層（Layer 2）：中低階圖案與紋理

開始偵測較為複雜的形狀與重複性圖案 5。

- **範例**：垂直紋理、圓形輪廓、細線條組合等 5。

### 第 3 層（Layer 3）：中階複雜圖案與物件區域

能識別更複雜的幾何圖形與特定物件的部分輪廓 6。

- **範例**：圓形車身輪廓（汽車）、人物特徵、蜂巢狀（Honeycomb）或方形規則紋理 6。

### 第 4 層（Layer 4）：高階特定物件與部件

開始出現針對特定類別或部件的檢測器 6 7。

- **範例**：特定犬種（Dog Detector）、水面波紋、鳥類的腿部結構 6 7。

### 第 5 層（Layer 5）：高階抽象物件與完整類別

能辨識極為複雜且抽象的完整物件，對於同類別內的外觀差異具備更高的涵蓋度與泛化能力 7。

- **範例**：外觀多樣的各式犬隻、鍵盤（及密集點狀紋理）、花朵、坦克等 7。

## 3. 核心總結與後續應用

- **特徵演進規律**：CNN 的學習過程是由淺層的簡單邊緣與顏色，逐步演進至中層的紋理與局部圖案，最後到達深層的複雜抽象物件 7。
- **後續應用**：對各層特徵抽象化的直覺理解，是進一步實現與建構**神經風格轉換（Neural Style Transfer）**演算法的基礎。

# 神經風格轉換損失函數（Neural Style Transfer Cost Function）重點筆記

## 1. 問題定義與目標

- **輸入資料**：內容圖片 $C$（Content Image）與風格圖片 $S$（Style Image）1。
- **生成目標**：生成一張全新的目標圖片 $G$（Generated Image）1。

## 2. 總損失函數 $J(G)$ 結構

為了評估生成圖片 $G$ 的品質，演算法定義了一個總損失函數 $J(G)$，包含兩個主要部分 1：

```math
J(G) = \alpha J_{\text{content}}(C, G) + \beta J_{\text{style}}(S, G)
```

- **內容損失（Content Cost）$J_{\text{content}}(C, G)$**：衡量生成圖片 $G$ 與內容圖片 $C$ 在內容上的相似程度 1。
- **風格損失（Style Cost）$J_{\text{style}}(S, G)$**：衡量生成圖片 $G$ 與風格圖片 $S$ 在風格上的相似程度 1。
- **權重超參數（$\alpha$ 與 $\beta$）**：用來設定內容損失與風格損失之間的相對權重 1。此雙參數設定沿用自演算法原作者 Leon Gatys、Alexander Ecker 等人的研究論文 1。

## 3. 演算法執行步驟

1. **隨機初始化**：將生成圖片 $G$ 初始化為隨機白雜訊圖片（例如尺寸為 $100 \times 100 \times 3$ 的 RGB 陣列）1。
2. **定義損失函數**：設定結合內容與風格的總損失函數 $J(G)$ 1。
3. **梯度下降法優化**：利用梯度下降法（Gradient Descent）來最小化 $J(G)$ 1。在此過程中，演算法會直接更新圖片 $G$ 的像素值 1。
4. **生成最終圖像**：隨著像素值的不斷調整，圖片 $G$ 會逐漸顯現出內容圖片 $C$ 的構圖，並融合風格圖片 $S$ 的藝術風格。

# 神經風格轉換：內容成本函數（Content Cost Function）

## 1. 演算法總結構

神經風格轉換的總成本函數主要由**內容成本（Content Cost）與風格成本（Style Cost）**兩部分組成 1。

## 2. 隱藏層 $L$ 的選擇

計算內容成本時，會選用預訓練卷積神經網路（例如 VGG 網路或其他神經網路）的某個隱藏層 $L$ 1。

- **層數過淺（如第 1 層）**：會強迫生成圖像（$G$）在低階視覺特徵（如邊緣、顏色與局部紋理）上與內容圖像（$C$）極為相似；這通常也會使兩者在像素與局部結構上更接近 1。
- **層數過深**：較著重高階語意特徵，可能只確保主要物件或高階結構存在，但不一定保留內容圖像的精確空間配置（例如內容圖若有狗，生成圖不只要有狗，也仍受所選層特徵的限制）1。
- **實際選擇**：通常選擇位於網路中間層的隱藏層 $L$，既不太淺也不太深 1。

## 3. 內容成本函數 $J_{\text{content}}(C, G)$ 的定義

令 $a^{[l](C)}$ 與 $a^{[l](G)}$ 分別代表內容圖像與生成圖像通過層 $L$ 時的隱藏單元激活值（Activations）1。

- 若兩者的激活值相似，代表兩張圖像具有相似的內容 1。
- **計算方式**：內容成本定義為兩張圖像在層 $L$ 激活值之間的元素級平方差之和（Element-wise sum of squared differences），即將激活值展開為向量後的 L2 範數平方 1。
- **歸一化常數**：前方可加入歸一化常數（例如 $\frac{1}{2}$ 等），其整體比例亦可透過超參數 $\alpha$ 進行調節 1。

## 4. 最佳化機制

在對總成本進行**梯度下降（Gradient Descent）**以尋找生成圖像 $G$ 時，內容成本會促使演算法找到一張讓層 $L$ 隱藏激活值與內容圖像儘可能接近的圖像 1。

# 風格成本函數（Style Cost Function）筆記整理

## 1. 圖像「風格」的直觀定義

- **通道間的相關性（Correlation）**：在神經網路的特定隱藏層 $L$ 中，圖像的「風格」可用不同激活通道（Channels）之間的相關／共現程度表示 1。
- **捕捉高階特徵的共現（Feature Co-occurrence）**：例如，若紅色通道負責偵測垂直紋理，黃色通道負責偵測橘色區塊，兩通道的高度相關性代表這兩種特徵傾向在圖像同一區域同時出現 2 3。
- **風格相似度**：若生成圖像 $G$ 與風格圖像 $S$ 的通道相關性特徵相似，則代表兩者具有相似的視覺風格 3。

## 2. 風格矩陣（Style Matrix / Gram Matrix）

為了量化風格，需分別為風格圖像 $S$ 與生成圖像 $G$ 計算風格矩陣（在線性代數中稱為 Gram 矩陣，記為 $G^{[l]}$）4（原始筆記註記：`more_horiz`）。

### 維度大小

風格矩陣為 $n_C \times n_C$ 的方陣，其中 $n_C$ 為該隱藏層的通道總數 4 7。

### 矩陣元素計算

第 $k$ 個通道與第 $k'$ 個通道之間的相關性元素 $G_{k, k'}^{[l]}$ 計算公式為：

```math
G_{k, k'}^{[l]} =
\sum_{i=1}^{n_H} \sum_{j=1}^{n_W}
 a_{i,j,k}^{[l]} \, a_{i,j,k'}^{[l]}
```

將高度 $n_H$ 與寬度 $n_W$ 所有位置上，兩通道激活值的乘積進行累加求和 4（原始筆記註記：`more_horiz`）。

### 統計意涵

此處計算嚴格來說是未正規化的通道激活內積或未中心化的交叉相關（Unnormalized channel inner product / uncentered cross-correlation），因為計算過程並未減去均值；因此不應嚴格稱為統計學上的協方差 5 9。

## 3. 單層風格成本函數（Layer Style Cost Function）

隱藏層 $L$ 的風格成本函數 $J_{\text{style}}^{[l]}(S, G)$ 即為風格圖像矩陣 $G^{[l](S)}$ 與生成圖像矩陣 $G^{[l](G)}$ 各元素差值的平方和（即 Frobenius 範數平方）6 10：

```math
J_{\text{style}}^{[l]}(S, G) =
\frac{1}{\left(2 n_H^{[l]} n_W^{[l]} n_C^{[l]}\right)^2}
\sum_{k} \sum_{k'}
\left(
G_{k,k'}^{[l](S)} - G_{k,k'}^{[l](G)}
\right)^2
```

前面的常數項為正規化係數，但在實際訓練中主要由超參數進行整體縮放 10。

## 4. 跨層風格成本與總目標函數（Overall Cost Function）

### 融合多層隱藏層風格

同時結合神經網路中多個隱藏層的風格成本，能獲得更佳的視覺效果 10。總風格成本為各層風格成本的加權和：

```math
J_{\text{style}}(S, G) =
\sum_{l} \lambda^{[l]} J_{\text{style}}^{[l]}(S, G)
```

這能讓網路同時考慮低階特徵（如邊緣）與高階特徵的相關性 11。

### 總目標函數

將內容成本（Content Cost）與總風格成本結合：

```math
J(G) =
\alpha J_{\text{content}}(C, G) +
\beta J_{\text{style}}(S, G)
```

利用梯度下降（Gradient Descent）優化生成圖像 $G$，即可合成出兼具內容與風格的神經藝術作品。
