# 物件定位與目標偵測（Object Localization & Detection）全系統學習筆記

---

## 1. 基礎概念與任務區分

在電腦視覺中，根據任務複雜度與輸出目標的不同，主要可分為以下三種核心範式：

| 圖像分類 (Classification) | 分類與定位 (Classification with Localization) | 物件偵測 (Object Detection) |
| :--- | :--- | :--- |
| 辨識影像中「是否有」特定類別物件。 | 辨識單一主要物件，並以紅色矩形邊界框（Bounding Box）標示位置。 | 同時在單張影像中辨識並定位多個不同類別與尺寸的物件。 |

## 2. 物件定位與標籤向量表示法

### 邊界框（Bounding Box）參數化表示
為了讓神經網路進行迴歸預測，邊界框採用**歸一化（Normalized）影像座標系**：
* **影像座標定義**：左上角為 $(0,0)$，右下角為 $(1,1)$。
* **四個核心幾何參數**：
  * $B_x, B_y$：邊界框**中心點（Center/Midpoint）**在影像中的相對 X、Y 座標（介於 $0$ 到 $1$ 之間）。
  * $B_w, B_h$：邊界框相對於整張影像總寬度與總高度的比例（介於 $0$ 到 $1$ 之間）。

### 目標標籤向量 $Y$（Target Label Vector）建構
以 3 個物件類別（如 $c_1$: 行人 $、c_2$: 汽車 $、c_3$: 機車）為例，單一物件定位的 8 維標籤向量定義如下：

$$Y = \begin{bmatrix} P_c \\ B_x \\ B_y \\ B_h \\ B_w \\ c_1 \\ c_2 \\ c_3 \end{bmatrix}$$

* **$P_c$（Confidence / Presence Probability）**：判斷影像中是否存在目標物件（存在為 $1$，背景/無物件為 $0$）。
* **有物件時（$P_c = 1$）**：完整填入邊界框座標 $(B_x, B_y, B_h, B_w)$ 與對應的單熱編碼（One-hot）類別標籤 $(c_1, c_2, c_3)$。
* **無物件時（$P_c = 0$）**：其餘 7 個維度皆標記為 **"Don't Cares"（?）**，在損失函數計算時不採計其梯度更新。

### 損失函數（Loss Function）設計
實際訓練時通常採用**混合損失函數（Hybrid Loss Function）**以確保多元目標同時收斂：
1. **物件存在機率 $P_c$**：採用邏輯迴歸損失（Logistic Regression Loss / Binary Cross-Entropy）。
2. **邊界框座標 $(B_x, B_y, B_h, B_w)$**：僅在 $P_c = 1$ 時計算平方誤差（Squared Error / Mean Squared Error）或 Smooth L1 Loss。
3. **類別標籤 $(c_1, c_2, c_3)$**：僅在 $P_c = 1$ 時採用對數概似損失（Log-likelihood / Softmax Cross-Entropy）。

## 3. 關鍵點檢測（Landmark Detection）

關鍵點檢測是比矩形邊界框更為通用的幾何定位技術，透過預測特定的座標點來精確描繪物件結構。

### 核心機制與輸出層設計
* **定義**：神經網路直接輸出 $N$ 個關鍵點的 $(x, y)$ 座標，即 $(l_{1x}, l_{1y}, l_{2x}, l_{2y}, \dots, l_{Nx}, l_{Ny})$。
* **輸出單元數計算**：以人臉標記 64 個關鍵點為例，輸出層需包含：
  
  $$\text{輸出維度} = 1 (P_c) + (64 \times 2) = 129 \text{ 個單元}$$

### 資料集標註一致性（Consistency）
* **人工標註**：訓練集需要極高精確度的人工標註。
* **一致性原則**：特定編號的點在所有訓練樣本中必須嚴格對應相同的解剖學或幾何位置（例如：$l_{1}$ 永遠代表左眼外眼角）。

### 實務應用場景
* **人臉辨識與情緒分析**：標記眼角、鼻尖、嘴唇輪廓與顎線，判斷笑臉、皺眉等表情。
* **擴增實境（AR特效）**：精確定位人臉特徵以進行虛擬飾品繪製（帽子、眼鏡）或動態臉部變形（Warping）。
* **人體姿態檢測（Pose Estimation）**：標記關節點（肩、肘、膝、手腕），重建人體骨架姿勢。

## 4. 目標檢測演算法的演進與實現

### 傳統滑動窗口演算法 (Sliding Windows)
* **訓練階段**：準備「緊密裁剪（Closely Cropped）」的目標圖像（如僅包含車輛的區域）訓練 ConvNet 分類器。
* **測試階段**：選定特定大小的窗口，以固定步長（Stride）在測試影像上滑動掃描，截取區域送入 ConvNet 分類；隨後放大窗口尺寸，重複多尺度（Multi-scale）掃描。
* **致命缺點（高昂計算成本）**：
  * **重複計算繁重**：圖像重疊區域被重複截取並單獨送入 ConvNet 執行前向傳播。
  * **步長與精度的權衡（Trade-off）**：大步長遺漏目標，小步長導致計算量爆炸。

### 滑動窗口的卷積實現 (Convolutional Implementation / OverFeat)
為了解決重複計算問題，將網路末端的**全連接層（FC）替換為 $1 \times 1$ 卷積層**，實現一次性前向傳播（Shared Computation）。

#### 將 FC 層轉為卷積層的範例：
* **輸入**：$14 \times 14 \times 3$
* **Conv & MaxPool**：降維至 $5 \times 5 \times 16$
* **FC1（400）** $\rightarrow$ 改用 400 個 $5 \times 5 \times 16$ 濾波器 $\rightarrow$ 輸出 $1 \times 1 \times 400$（數學上完全等價）
* **FC2（400）** $\rightarrow$ 改用 400 個 $1 \times 1$ 濾波器 $\rightarrow$ 輸出 $1 \times 1 \times 400$
* **Softmax** $\rightarrow$ 改用 4 個 $1 \times 1$ 濾波器 $\rightarrow$ 輸出 $1 \times 1 \times 4$

#### 卷積化共享計算：
若直接將 $16 \times 16 \times 3$ 的大圖送入上述網路，最終將輸出 $2 \times 2 \times 4$ 的特徵圖：
* 輸出的左上角 $1 \times 1 \times 4$：對應原圖左上角 $14 \times 14$ 區域的檢測結果。
* 輸出的右上角 $1 \times 1 \times 4$：對應原圖右上角 $14 \times 14$ 區域的檢測結果。
* **總結**：原本需要執行 4 次前向傳播的過程，簡化為單次卷積計算。但其缺點為**邊界框定位精度仍受限於池化層帶來的步長限制**。

## 5. 評估指標與後處理優化

### 交併比 (Intersection Over Union, IoU)
IoU 是量化預測框（Predicted Box）與真實框（Ground Truth Box）重疊程度的客觀指標：

$$\text{IoU} = \frac{\text{交集面積 (Intersection Area)}}{\text{聯集面積 (Union Area)}} = \frac{A \cap B}{A \cup B}$$

```
    預測框 (Predicted)
   +---------+
   |         |
   |    +----+----+  <-- 交集區域 (Intersection)
   |    |////|    |
   +----+----+    |
        |         |
        +---------+  真實框 (Ground Truth)
```

* **數值範圍**：$0$ 到 $1$（$1$ 代表物理上的完美重疊）。
* **判定門檻（Threshold）**：
  * **$0.5$（一般慣例）**：最通用的基準，當 $\text{IoU} \ge 0.5$ 判定為正確定位（True Positive）。
  * **$0.6 \sim 0.7$（嚴謹標準）**：應用於醫療影像或工業瑕疵檢測。

### 非極大值抑制 (Non-Maximum Suppression, NMS)
為了解決同一個物件被多個鄰近網格重複預測的問題，必須透過 NMS 進行清理。

```
原始重複邊界框               執行 NMS 後
  +---+ +---+               +---+
  |   | |   |       -->     |   |
  +---+ +---+               +---+
 (多個高 IoU 候選框)        (僅保留最高 Confidence 框)
```

#### NMS 執行步驟（單一類別）：
1. **門檻過濾**：捨棄所有信心度 $P_c \le 0.6$（預設值）的邊界框。
2. **選取極大值**：在剩餘候選框中，挑選機率 $P_c$ 最高者作為確定輸出並高亮顯示。
3. **抑制重疊框**：計算其餘邊界框與該高亮框的 IoU，將所有 $\text{IoU} > \text{NMS Threshold}$ 的邊界框全數捨棄/抑制。
4. **疊代執行**：重複步驟 2 與 3，直到所有候選框皆處理完畢。
5. **多類別延伸**：若需偵測 $K$ 個類別，必須**獨立執行 $K$ 次 NMS**。

## 6. YOLO 與 Anchor Boxes 機制

YOLO (You Only Look Once) 將目標偵測轉化為單一端到端（End-to-End）迴歸問題。

### Anchor Boxes：突破單一網格的偵測瓶頸
在傳統 YOLO 中，每個網格（Grid Cell）僅能負責預測一個物件（物件中心點落入的網格）。當多個物件中心點落入同一網格（例如行人站在汽車前方）時，會造成嚴重漏檢。

#### 解決方案：引入 Anchor Boxes 專用化分工
預先定義多組不同長寬比的幾何參考框（如 Anchor 1 為瘦長形針對行人，Anchor 2 為寬扁形針對汽車）。

```
+---------------------------------------------------------------------------------+
|                                 16維預測向量 (y)                                 |
+-------------------------------------------------+-------------------------------+
|                  Anchor Box 1                   |          Anchor Box 2         |
| [ p_c, b_x, b_y, b_h, b_w, c_1, c_2, c_3 ]      | [ p_c, b_x, b_y, b_h, b_w, ...|
+-------------------------------------------------+-------------------------------+
```

* **Y 向量維度擴張**：若採用 $B$ 個 Anchor Boxes 與 $C$ 個類別，每個網格的輸出向量維度為：
  
  $$\text{維度} = B \times (1 + 4 + C)$$

  $$(以 $19 \times 19$ 網格、5 個 Anchor Boxes、3 個類別為例，總輸出張量為 $19 \times 19 \times 40$)$$
* **Ground Truth 分配邏輯**：當物件中心落入某網格時，系統會計算該物件的 Ground Truth 框與該網格所有 Anchor Boxes 的 **IoU**，並分配給 **IoU 最高** 的 Anchor Box 負責預測。
* **Anchor Box 選取策略**：
  * **手動挑選**：依經驗預設 5～10 種典型長寬比。
  * **K-means 聚類法（自動選取）**：對訓練集的所有 Ground Truth 框進行幾何形狀聚類，自動生成最貼近資料集真實分布的形狀基準。

## 7. R-CNN 系列演進與兩階段法

R-CNN 系列代表了兩階段目標偵測器（Two-stage Detectors）的發展路徑。

```
R-CNN
 (Selective Search -> 2000 個 RoI -> 逐一送入 CNN 提取特徵 -> SVM 分類 & Bounding Box 迴歸)
   │
   ▼
Fast R-CNN
 (整張大圖先過 CNN 提特徵 -> 特徵圖上裁切 RoI -> 特徵共享池化 -> 聯合損失函數)
   │
   ▼
Faster R-CNN
 (引入 RPN 區域候選網路 -> 端到端神經網路 -> 擺脫 CPU 運算瓶頸)
```

### 關鍵組件：邊界框迴歸 (Bounding Box Regression)
無監督區域建議演算法（如 Selective Search）產生的邊界框通常較粗糙，模型需透過學習幾何偏移量 $(B_x, B_y, B_h, B_w)$ 進行邊界框迴歸，以實現自我糾偏與高精度對齊。

### R-CNN 系列技術演進對比

| 特性 | R-CNN (2014) | Fast R-CNN (2015) | Faster R-CNN (2015) |
| :--- | :--- | :--- | :--- |
| **建議框生成方式** | 傳統 Selective Search | 傳統 Selective Search | **區域候選網路 (RPN)** |
| **核心技術創新** | 兩階段區域分類與迴歸 | **特徵共享 (Feature Sharing)** | **端到端（End-to-End）全網路檢測** |
| **主要效能瓶頸** | 2000 次重複卷積計算 | CPU 端的 Selective Search | 兩階段架構導致結構與計算複雜度較高 |
| **相對推理速度** | 極慢（~47s / 圖） | 中等（~2s / 圖） | 快（~0.2s / 圖） |

## 8. 一階段與兩階段偵測器對比總結

```
                         目標偵測演算法架構
                                │
        ┌───────────────────────┴───────────────────────┐
        ▼                                               ▼
  一階段法 (One-stage)                             兩階段法 (Two-stage)
  代表：YOLO, SSD                                  代表：Faster R-CNN
  策略：All-at-once                                策略：Propose then Classify
  優勢：推理速度極快、架構簡潔                     優勢：小物件與高精度定位表現優秀
  劣勢：對於密集小物件定位難度較高                 劣勢：計算量較大、難以達到極高 FPS
